# Audit 4: BLUEPRINT V1·§11 보관소 상태 대조

검증일: 2026-11-03. 노드: `audit4-blueprint-status-sync`.
연결: A1·A2·A4, L1·L2, I6, V1, 제품 목적 대응표 P02·P03의 근거 관리.

## 확인과 변경

작업 시작 시 §9.2 V1은 이미 Cloudflare R2와 ADR-0016을 명시했고,
§11도 같은 R2 보존·다운로드 대조 기록을 표시했다.
[Audit 2 정정 기록](2026-10-27_blueprint_s3_r2_drift.md)도 이 상태를 확인한다.
따라서 이번 작업에서 S3 오표기가 새로 수정됐다고 주장하지 않는다.

§9.2의 제공자 문장을 ADR-0016에 따라 R2로 확정했다는 표현으로 정리하고,
[ADR-0016](../../decisions/ADR-0016-원본-보관소-R2.md) 직접 링크를 추가했다.
S3는 ADR-0015의 대체된 선택이라는 이력으로만 남는다.
V1 관문 미통과와 파생 재현·다른 계열 AI 검수·화면 열린 항목은 유지한다.

## 회귀 검사와 증거

`tools/tests/test_storage_provider_docs.py`에 V1의 ADR 직접 링크 검사를 추가하고,
기존 R2 기록 대조 검사를 §11까지 확장했다.

- §9 V1과 §11 데이터 행이 같은 2026-10-09 R2 보존·다운로드 대조를 명시한다.
- 원본 58키·파생 v2 61키가 두 절 및 GAP 보고서와 일치하며,
  고정 R2 목록의 모든 결과가 `byte_identical`이고 원본·다운로드 해시가 같다.
- V1과 §11 마일스톤 행 모두 완전 재현 8/14건과 파생 6건의 남은 작업을 표시한다.
- 기존 검사가 현재 R2 결정·대체된 S3 이력·D-04/O14/O17 관문과 V1 미통과를 계속 확인한다.

실행 로그: [tools/evidence/audit4-blueprint-status-sync/](../../../tools/evidence/audit4-blueprint-status-sync/).
문서 수정 전에는 새 직접 링크 검사만 실패했고(15개 중 1개), 수정 후 15개 모두 통과했다.
Python 전체 1,346개 실행(6개 건너뜀), Rust 전체 495개 통과(1개 무시),
온톨로지 실행기 4개 통과, BLUEPRINT 상태·수치·검증 자료·설계 명세 검사도 통과했다.
명령·전체 로그는 같은 디렉터리의 [README](../../../tools/evidence/audit4-blueprint-status-sync/README.md)에 기록한다.

## 범위와 한계

고정된 2026-10-09 관측 기록에 대한 로컬 문서·회귀 검증이다.
이번 작업에서 R2 접속·업로드·재다운로드를 실행하지 않았고 새 운영 결정을 내리지 않았다.
§11의 결정 색인·기준일은 ADR/DEC 변경이 없어 유지한다.
이 기록은 P02·P03의 실제 전 상품 수집·변경 전파 또는
P01~P19·T-OP-08의 소비자 화면·첫 출시 완료 증거를 대체하지 않는다.
