# D-04 — 기존 R2 토큰 유지·사용에 대한 소유자 위험 수용

상태: 해결(소유자 직접 결정). 결정자·위험 수용자: 준태님(소유자).
최초 결정: 2026-10-13 17:53 KST. 확인: 2026-11-02. 재확인: 2026-11-10.
근거: [DEC-D-04](../../decisions/DEC-D-04.md)와 이번 소유자 지시("my decision is your decision").

대화에 노출된 **기존 R2 토큰은 계속 유효하게 유지하고 폐기·재발급 없이 사용한다**.
노출에 따른 비인가 접근, 객체의 열람·변경·삭제, 비용 발생 위험을 소유자가 명시적으로 수용했다.
토큰은 계정 전체 권한일 가능성이 있으며 권한 범위를 이번 작업에서 확인하지 않았다.
범위 제한·교체·폐기를 완료한 것으로 표현하지 않는다. 추가 소유자 결정을 기다리는 사안이 아니다.

기존 토큰은 **ONJEON box secrets env에서만 읽는다**. 대화·저장소·문서·설정 파일에서 토큰을
복사하거나 복구하지 않는다. 토큰 값의 출력·로그·봉투·증거 파일 기록을 금지한다.
데몬이 R2 토큰을 갖지 않는 규칙은 유지하고, 필요한 R2 실행 경로에서만 해당 환경을 사용한다.
이 변경은 환경 준비나 실제 접근 성공을 증명하지 않는다.

## 작업 게이트 적용

[tasks.json](../proposals/설계검토_결과/tasks.json)의 D-04 start·real_data 차단을 제거한다.
decision_index.D-04의 네 목록은 비워 해결 이력을 남기며 추가 decisions_recorded 등록을 요구하지 않는다.

| 과제 | D-04 해결 후 | 별도로 유지하는 조건 |
|---|---|---|
| T-DT-01 | 기존 토큰으로 R2 보존 경로 사용 가능 | 작업 파일·원장·비용·불변 보존 규칙 |
| T-DT-04 | R2 토큰 폐기·재발급 차단 없음 | O19 국내 IP 환경, O17 대량 자동 수집 차단 |
| T-OP-02(b) | R2 보존의 D-04 차단 없음 | D-02 실제 검수, 실제 검수·보존·관통 증거 필요 |
| T-OP-04 | D-04 시작 차단 없음 | O14 병합 승인, O17 대량 자동 수집 차단 |

O14·O17·D-02·O19와 모든 다른 게이트, BP-D-16~BP-D-18 및
[ADR-0017 비용 제한](../../decisions/ADR-0017-R2-비용-제한.md)은 변경하지 않는다.
지정 환경 하나·동시 실행 1개·수동·고정 키 작업 범위, 작업 파일·원장·요청·바이트·재시도·시간 한도와
조회 실패 시 중단도 유지한다. O17의 **대량 자동 수집** 선행 조건에 남은 토큰 재발급은 이번 변경으로
삭제하거나 충족 처리하지 않는다. 그 조건은 위 네 과제의 D-04 차단을 되살리는 근거가 아니다.
기존 R2 토큰 이외의 `cfut_` 토큰에 대한 폐기·재사용 금지 규칙도 유지한다.

## 재검토 조건

다음 사건이 관측되면 소유자에게 위험 수용 재검토를 요청한다. 이 문서는 자동 폐기·재발급을 지시하지 않는다.

- 비인가 접근·호출 또는 자격 증명 오용 징후.
- 예상하지 않은 객체 생성·변경·삭제, 해시 불일치 또는 원장 변경.
- 청구·사용량 이상 또는 원장과 청구의 불일치.
- 소유자의 후속 지시, 토큰 권한 범위·운영 환경 변경 또는 O14·O17·비용 정책 개정.

과거 [2026-10-26 정정](2026-10-26_o13_d04_ruling.md)의 D-04 접근 차단 유지·추가 결정 요구는
최신 소유자 결정으로 대체되며 당시 실행 증거는 보존한다.
