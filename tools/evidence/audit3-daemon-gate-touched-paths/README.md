# audit3-daemon-gate-touched-paths

기준 커밋 `e1c5f14c0de0e428e46fcb975e412f909d9557ed` 위 작업 트리의 로컬 실행 증거다. 변경 내용·실행 명령·결과·한계는 [감리 기록](../../../docs/blueprint/audits/2026-10-28_daemon_gate_touched_paths.md)에 있다.

`before.log`는 수정 전 최초 회귀 시험 12개의 실패 기록이고 `focused.log`는 최종 15개 회귀 시험의 통과 기록이다. 전체 데몬 보고서와 소스 해시는 [reports](../../daemon/reports/)에 있다. `ci-tests.log`의 의존성 검사 실패 2개는 `ci-baseline.log`에서 기준 커밋과 같은 위반 3건임을 확인했다. 이 디렉터리의 시험 통과는 제품 출시 완료 증거가 아니다.

`round1/`은 리뷰 P1(R-10 검사 우회)의 수정·재검증 기록이다. 기준은 `847596e8641de2546fe7bfb37e159a0d370fd900` 위 작업 트리다. `round1/before.log`는 합성 비밀값과 범위·본문 오류의 조합 5건이 실패한 재현이고, `round1/focused.log`는 추가 시험 5개를 포함한 20개 통과 기록이다. 데몬 보고서는 수정 1차의 281개 시험·704건 dry-run 검사와 소스 해시로 갱신했다. 나머지 최초 증거는 그대로 보존했다.

`round2/`는 main과의 생성 보고서 충돌을 해소한 뒤 양쪽 변경을 함께 검증한 기록이다. 현재 데몬 보고서는 287개 시험·692건 dry-run 검사와 합쳐진 소스 해시를 기록한다. `focused.log`는 결과 관문과 main의 시험 실패 재임대 회귀 시험 26개를 함께 실행한 결과다. `ci-baseline.log`는 추가 CI의 기존 의존성 위반이 양쪽 병합 입력에서도 동일함을 확인한다. 전체 명령과 결과는 감리 기록의 수정 2차 절을 따른다.
