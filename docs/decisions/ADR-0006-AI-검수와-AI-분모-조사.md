# ADR-0006 AI 검수와 AI 분모 조사

상태: 확정(사용자 결정) | 날짜: 2026-10-08 | 근거: 제3부 §57

## 맥락

v0.3은 지급 조건·금액 같은 중요 항목(C0)을 도메인 전문가가 전수 승인하고 정답셋도 전문가가 만들도록 했다. 사용자는 사람이 검수하지 않고 AI가 검수하며, 분모 조사도 AI가 하도록 결정했다.

## 결정

1. 건별 검수는 AI 에이전트만 한다. 작성 에이전트와 승인 에이전트는 서로 다른 모델 계열이다.
2. 모델 일치는 독립 증거가 아니라는 v0.3 §30.2를 유지한다. 독립성은 이종 모델·이종 입력 표현·LLM이 아닌 코드 검사·레드팀·교차 문서 검증의 결합으로 얻는다.
3. 에이전트 사이의 불일치와 레드팀 반례는 다수결 대신 `hold`로 처리한다.
4. 사람 정답이 없으므로 품질은 합성 약관 변이 주입, 공시 예시 재현, 교차 문서 일치율, 표본 재추출 감사, 사용자 신고·제출 견적 환류로 잰다.
5. 서킷 브레이커가 임계 초과 시 해당 규칙의 계산을 자동 중단한다. 사람은 정책 소유자 1인이 임계값·모델 구성·사고 시 중단/재개를 정책 수준에서 정한다(가정).
6. 분모 조사는 서로 다른 경로의 조사 에이전트 둘과 대조 에이전트가 하고, 두 번 포획 추정으로 누락을 추정한다. 추정치로는 "전수"를 선언하지 않는다.
7. 화면·웹에는 "전문가 검수"·"검수 완료"를 쓰지 않고 "AI 검증"으로 표기한다.

## 위험

- 모든 에이전트가 같은 방향으로 틀리면 감지되지 않는다(제3부 R14). 측정치는 실제 오류율의 보증이 아니다.
- 완화: 이종성 확보, 서킷 브레이커, 증거 보기·오류 신고 상시 제공, 보류를 허용하는 설계.
- AI가 놓친 분모 항목은 AI 조사로는 드러나지 않을 수 있다. 사용자 PDF에서 분모 밖 상품이 나오면 자동 재조사를 건다.
