**Decision:** Keep 판단 기준 관리 as knowledge responsibility area C (module services/criteria and data/criteria, not a separate service). This confirms the owner decision of 2026-10-12 rather than deciding it again. The rest of D-08 is the service-application gate in 02_구현계약 §1.5. (1) Default needed amounts are not offered in the first release: every criteria_application has defaults_enabled=false and no defaults_basis_ref. T-KN-13 still loads candidates (sourced public statistics only, with target and update cycle), but users never see them. Amount judgements use user_assumption only. If an empty assumption would change the verdict, the result is hold and decisive_inputs asks for it; never fill with 0 or an average. defaults_enabled=true needs a separate owner decision record that gives the source (agency, table, year), target, update cycle, the formula from statistic to amount, and the on-screen label. (2) A criterion_version may enter a criteria_application with approval_ref.decision_id=DEC-D-08 only if all of these hold: its evidence_kind includes public_statistic, statute, regulator_notice or terms_fact (not editorial alone); scope is stated; it is in a frozen criteria_release; it produces no amount (reference_stat is shown as reference with source and date only); and it produces no score, ranking or sign-up recommendation. Editorial criteria such as priority_rule need per-criterion owner approval. approved_by records the real approver; autoloop-made records are never labelled as owner-approved. (3) Recommended additions to the T-KN-14 test need-criteria-service-gate: reject DEC-D-08 records that have defaults_enabled=true or contain editorial-only versions. (4) Registering D-08 lifts only T-KN-14's release gate. The gate is closed by default, so registration opens no defaults. O05 stays open, and this decision follows its default (user-entered assumptions only; no made-up default needed amount).

**Why:** The governing docs forbid unsourced defaults (SYSTEM_CONTRACT: no default needed amount while the statistic's source is unconfirmed; the O05 default; BLUEPRINT §2: no unsupported coverage ratio). The repo has no sourced statistic candidates: data/criteria does not exist and T-KN-13 has not started. Even with a statistic, the formula that turns a population average into one person's need has no source, so a prefilled value would be false certainty. Applying defaults or editorial criteria to real consumers touches the financial-advice and solicitation boundary, so that choice is left to the owner. Leaving D-08 open blocks the T-KN-14 release, T-OP-08 and the first release. A closed-by-default gate plus sourced non-editorial criteria unblocks the release and still gives sourced reasons (e.g. the National Health Insurance co-payment structure) for P17. The record is reversible and touches no money, secrets or deployment.
