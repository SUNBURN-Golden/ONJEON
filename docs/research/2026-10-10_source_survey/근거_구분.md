# 접근 정책·법령 주장의 근거 구분

2026-10-10 | 상태: 토의 자료(관측 기록). 설계 결정이 아니고 법률 의견도 아니다.

조사 기록(A~F)과 [설계 제안](../../blueprint/proposals/수집_지식기반_설계_제안.md)에 나온 접근 정책·법령·규정 주장마다 다음 셋을 나눈다.

- **확인한 원문**: 받은 원문 파일, 그 판(시행일), 1차인지 2차인지
- **적용 범위**: 그 원문이 누구에게, 무엇에, 어느 시점에 적용되는지(원문 문언에서 읽히는 범위만)
- **미확인**: 확인하지 않은 것, 조사자의 해석, 법률 판단이 필요한 것

## 1. 근거 등급과 대조 방법

| 등급 | 뜻 |
|---|---|
| 1차 | 이 세션에서 발행처 사이트(law.go.kr, fsc.go.kr, rfc-editor.org, 협회, 회사)에서 직접 받은 원문 |
| 2차 | 발행처가 아닌 곳의 사본(GitHub 법령 미러 legalize-kr, 제3자 저장소) |
| 요약 | WebFetch 도구가 돌려준 요약. 원문 바이트를 보존하지 않았다 |
| 조사자 판단 | 원문에서 직접 읽히지 않는 해석 |

**대조 방법**: 인용문 43건을 받은 원문 파일에서 공백을 지운 문자열 일치로 다시 찾았다(스크립트와 목록은 세션 임시 영역 `survey/G_verify/`). 41건은 그대로 찾았고 2건은 아래처럼 정리했다.

- 생보협회 "상품의 고유코드 5자리"는 별지가 아니라 시행세칙 본문(304행 "⑥ 자사코드")에 있다. 위치만 고친다.
- "분기별 보험상품 판매 목록"은 시행령 제71조④에 있고, 감독규정 제7-53조②에는 "보험상품 판매 목록"만 있다. 감독규정은 근거를 "영 제71조제3항"으로 인용하는데, 받은 시행령에서 ③은 "삭제 <2021. 6. 1.>"이고 해당 내용은 ④에 있다. 또 시행령 문언은 "제출하게 **할 수 있다**"(금융위 재량)이다. F 기록의 "제출한다"는 이 문언으로 고친다(§4).

대조는 인용문이 원문에 **있는지**만 확인한다. 조문 번호와 항의 대응, 문맥 해석은 별도로 확인하지 않았다(아래 각 행의 미확인 칸).

## 2. 접근 정책

### 2.1 RFC 9309(Robots Exclusion Protocol) 원문

- **확인한 원문(1차)**: `https://www.rfc-editor.org/rfc/rfc9309.txt`, 2026-10-10T03:57:46Z, sha256 `f633915d…`. 사이트 robots.txt(`/rfc/` 금지 없음)를 먼저 받았다. 요청 로그: [requests/G_verify.tsv](requests/G_verify.tsv). RFC 9309, Standards Track, 2022년 9월.
- **이 조사에서 쓴 조항**:

| 조항 | 원문 | 쓰인 곳 |
|---|---|---|
| §2.2.1 | "If no group matches the product token and there is no group with a user-agent line with the "*" value, or no groups are present at all, no rules apply." | `*` 그룹 없이 특정 봇(Yeti·Googlebot)만 적은 robots(klia, KB손보, data.go.kr, 예보) |
| §2.2.2 | "The crawler SHOULD ignore "disallow" and "allow" rules that are not in any group (for example, any rule that precedes the first user-agent line)." | User-agent 줄이 없는 robots(DB손보) |
| §2.3.1.1 | "If the crawler successfully downloads the robots.txt file, the crawler MUST follow the parseable rules." | 200으로 HTML(WAF 페이지·오류 페이지)이 온 경우 |
| §2.3.1.3 | "If a server status code indicates that the robots.txt file is unavailable to the crawler, then the crawler MAY access any resources on the server." (400~499) | 403·404·417 |
| §2.3.1.4 | "If the robots.txt file is unreachable due to server or network errors, … the crawler MUST assume complete disallow." | 타임아웃·TLS 실패 |
| §1 | "These rules are not a form of access authorization." | 전체 |

- **적용 범위**: 수집기가 robots.txt를 어떻게 해석할지에 대한 기술 표준이다. robots가 허용해도 그것이 접근 권한을 주지 않는다(§1). 이용약관, 저작권, 정보통신망 관련 법령, 개인정보 관련 법령, 서비스 방해 여부는 다루지 않는다.
- **미확인**:
  - 각 사이트 이용약관의 자동 수집·복제 조항(한 곳도 확인하지 않았다)
  - 공시 원문의 저작권·이용허락 표시(공공누리 등)
  - 국내 법령상 공개 웹페이지 자동 수집의 허용 범위. 이것은 법률 판단이며 이 문서는 판단하지 않는다.

## 3. 법령·규정

판은 이번에 받은 **수집 시점의 현행판**이다. 과거 판매 당시에 적용된 판은 확인하지 않았다. 조문을 과거 판매 구성에 적용하려면 그 시점의 판이 필요하다.
