# 라벨 사전 v1 — 작성·검토 대기

[DEC-O03](../../docs/decisions/DEC-O03.md)는 담당 작업과 차단 범위를 기록한다. 사전 내용과 코드 개정판 매핑은 아직 미정이며 이 디렉터리는 승인된 사전이 아니다.

- T-KN-05(S1): M1 완료 전에 라벨 사전 v1 후보, 종류별 정의·포함/제외 예·근거 연결 규칙, 질병 코드 체계·개정차수·시행일·공식 출처·판 간 매핑을 작성하고 데이터 정책 책임의 검토를 요청한다. 미확정 매핑은 공백으로 남긴다.
- 종류: 보장 대상, 지급 사유, 제외, 면책, 감액, 한도, 갱신, 가입 제약, 담보 간 관계, 특약 종속. 이 목록은 P04와 T-KN-08의 기존 수락 범위이며 세부 라벨 정의를 확정하지 않는다.
- T-KN-08(S2): 승인된 사전 판을 소비한다. `label-kinds-complete`는 종류마다 실제 표본의 accepted 주장과 basis 근거를 요구한다. 누락 종류는 KnowledgeGap으로 기록하고 시험 실패로 남긴다.

O03의 release 관문은 정규 라벨 승격에만 적용한다. 사전 판·내용 해시·코드 매핑·검토 증거를 DEC-O03에 연결하고 별도 결정 등록을 해야 한다. 후보 추출·형식 정의·로컬 시험·병합은 허용한다. D-02 검수 조건은 그대로다.

knowledge 서비스의 승격 경로는 아직 없으며 T-KN-05가 미등록 O03·미승인 사전·불명확 매핑을 거부하는 검사와 시험을 구현해야 한다. 이 안내·결정 기록·정적 검사 통과는 사전 승인·승격 검사 구현·M1·P04 완료 증거가 아니다.
