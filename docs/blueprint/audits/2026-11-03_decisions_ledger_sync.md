# Audit 4 — 결정 원장·설계도·인계 동기화

대상: `audit4-decisions-ledger-sync`, 2026-11-03.

감리 지적의 9개 DEC 기록을 포함해 현재 18개 DEC를 대조했다. 원장 §3.1에는 7개만 색인돼 있었고, BLUEPRINT §12는 AI 구성·소유자 결정을 M2 전체의 미정처럼 읽히게 했다. O01·O04는 이미 해결 근거가 있었으나 O12 행에는 의미론 결정의 해결 여부가 명시되지 않았다. 그록봇 인계 §10.3은 기록된 DEC도 모두 결정 대기로 묶었고 §10.2에는 결정 원문·원장으로 가는 탐색 경로가 없었다.

현재 [원장](../DECISIONS.md)은 전체 DEC에 상태·범위·남은 조건을 기록한다. O01은 ADR-0018, O04는 DEC-O04로 해결 상태를 유지하며 O12는 의미론 결정 질문을 해결로 표시한다. O12는 여전히 위임·가역·사용자 확정 아님인 잠정 개발 기준이다. T-TW-04·05 release 등록과 연산별 S6 검증은 별도이며 S6 미충족 연산은 capability-blocked다. [BLUEPRINT §12](../../BLUEPRINT.md#12-열린-결정)는 D-02 구성·소유자 결정과 접근·월 한도·임계값의 잔여 조건을 구분하고, 다른 기록된 개발 기준도 원문과 연결한다.

[결정 디렉터리 색인](../../decisions/README.md)과 [인계 §10.2](../proposals/설계검토_결과/그록봇_인계/README.md)는 원장·설계도·원문을 연결한다. DEC 원문·tasks.json·데몬 등록·실제 접근·플래그는 변경하지 않았다. D-04의 토큰 미폐기 결정은 실제 R2 접근 허용으로 해석하지 않으며 O14·O17의 미정값과 적용 승인도 유지한다. DEC-BUNDLE-STATUS는 ADR-0019의 09·tasks.json 한정 채택으로 부분 대체된 상태를 반영한다.

회귀 검사는 전체 파일 집합과 원장·디렉터리 색인의 일대일 대응, 각 결정의 실질 요약·제약, O01·O04·O12 해결 및 잔여 조건, D-02 범위, 인계 링크와 로컬 링크 유효성을 확인한다. 기존 전체 Python CI가 새 시험을 자동 발견한다. [실행 명령·결과·로그](../../../tools/evidence/audit4-decisions-ledger-sync/README.md).

이는 문서 정합성 finding의 완료 증거다. 09 P01~P19의 실제 수집·검수·트윈·소비자 화면·출시 완료 증거를 대신하지 않는다. 새 지출·법적 판단·비밀값·운영 배포 결정을 하지 않았다.
