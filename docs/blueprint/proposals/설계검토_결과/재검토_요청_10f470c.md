## 5. 검증하지 않은 것

- S02·S03은 규칙 파일, 문서, 시험 명세가 서로 맞는지까지만 확인했다. 실제 강제 종료, 쓰기 금지 격리, 정지 판정, 보존 커밋 해시 일치, 실제 전달 경로의 재전송은 확인하지 않았다. 모의 코어(T-OP-00)와 실제 실행기(T-OP-09)가 아직 없기 때문이다. "보존본에 쓰기가 섞이지 않는다", "재시도가 중복으로 막히지 않는다"는 실행으로 증명되지 않았다.
- S01은 토의 자료 검증기 수준의 동작 검증이다. 서비스 입력 단계(T-TW-01)는 아직 설계만 있다.
- 보존 전용 자격의 발급·회수와 쓰기 금지 격리는 호스트·저장소 설정이며, 사람이 준비해야 한다.
- 설계 담당과 구현자는 둘 다 claude 계열이다. 검사기도 구현자가 썼다.
