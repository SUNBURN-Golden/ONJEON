## 0. 최상위 기준(사용자 원문 요지)

- 만드는 것은 **세 부분이 끝까지 연결된 완성품**이다: 철저한 데이터 수집·관리·레이블링 → 그것을 기반으로 한 수준 높은 디지털 트윈 → 소비자가 쉽게 이해하는 직관적 UX/UI.
- 목적은 보험 소비자와 공급자 사이의 **정보비대칭을 줄이는 것**이다. 소비자가 설계사의 설명을 검증하고, 불필요하거나 불리한 선택을 스스로 구별할 수 있어야 한다.
- 이 목적은 소개 문장이 아니라 **실제 작업과 완료 기준**에 연결된다(아래 표의 "구현 작업"·"완료 증거" 칸, tasks.json의 done_criteria·required_test_ids).
- **일부 상품 시연이나 자동 개발 데몬 완성을 첫 출시 완성품으로 바꾸지 않는다.** 데몬 과제(T-OP-00·T-OP-09)는 개발 도구이며 출시 완성품의 일부가 아니다. 최종 관문(T-OP-08)은 이 표의 모든 행(축소·후속 표시 제외)이 등록부 증거로 닫혀야 통과한다.
- 칸의 뜻: 완료 증거 = 실제 데이터·실제 화면 시험·출시 증거(`docs/release-readiness/evidence/`). 합성 픽스처 통과는 증거가 아니다. "축소·후속" 칸은 근거(사용자 결정 ID·정본)가 있을 때만 채운다. 근거 없는 축소는 없다.

## 6. 최종 관문과의 연결

- T-OP-08의 완료 기준에 "09의 모든 행(축소·후속 표시 제외)이 등록부 증거로 닫힘"을 넣었고, 판정기 시험 `purpose-rows-all-closed`가 P01~P19 각 행의 구현 작업이 post_merge 상태이고 완료 증거 로그가 있는지 검사한다. 축소·후속 칸이 있는 행은 그 근거(결정 ID·정본)가 있을 때만 제외로 인정한다(scope_decision과 같은 규칙).
- T-OP-08의 선행은 T-OP-07(리허설: 공개 웹·전 화면·운영)·T-KN-14·T-CT-07·T-OP-00·T-OP-09이며, 이 표의 모든 과제는 T-OP-07 또는 T-MB-03·T-WB-01·T-KN-10을 거쳐 T-OP-08의 전이적 선행이다(spec_check G4b).
- 새로 연결한 완료 기준·시험 ID: `acquisition-reason-not-counted`(T-DT-04), `coverage-status-counts-acquired-only`(T-AP-04), `label-kinds-complete`(T-KN-08), `switch-diff-evidence-trace`·`multi-contract-relation-trace`(T-TW-05), `first-view-priority`·`decisive-conditions-not-hidden`·`no-composite-score`(T-MB-03·T-MB-04·T-AP-07), `purpose-rows-all-closed`(T-OP-08).

## 7. 이 표가 말하지 않는 것

- 행이 있다고 구현된 것이 아니다. 전부 설계이며 완료 증거는 아직 없다. 08 §4와 같다.
- P02·P03의 원본 관측 무결성 로컬 검증: [Audit 2 추가 메타데이터의 예약 키 거부](../../audits/2026-10-26_archive_extra_reserved_keys.md). 기본 필드 7개의 덮어쓰기와 객체가 아닌 메타데이터를 보관소 쓰기 전에 거부하고, 정상 추가 정보·재실행·기존 보관 내용의 바이트 보존을 검사한다. 실제 공시 확보율·R2 관측 목록 대조·화면·출시 완료 증거를 대체하지 않는다.
- P02·P03의 원본 보관·복원 무결성 로컬 검증: [Audit 2 표본 보관 전·복원 쓰기 전 SHA-256 검증](../../audits/2026-10-26_archive_samples_verify_before_put.md). 표본 목록과 다른 캐시 바이트는 원본·관측·파생물로 쓰지 않고, 손상된 보관 객체는 복원 대상 생성·덮어쓰기 전에 거부한다. 실제 공시 확보율·R2 관측 목록 대조·변경 재처리·화면·출시 완료 증거를 대체하지 않는다.
- P02·P03의 원본 보관 비용 통제 로컬 검증: [Audit 2 R2 엔드포인트 말미 점의 예산 검사 우회 차단](../../audits/2026-10-26_r2_endpoint_trailing_dot.md). 말미 점 주소의 R2 분류·작업 없는 클라이언트 생성 차단·계량기 연결을 모의 클라이언트와 Stubber로 검사한다. 실제 R2 요청·공시 확보율·관측 목록 대조·출시 완료 증거를 대체하지 않는다.
- P01·P02·P03의 수집 도구 로컬 검증: [Audit 2 robots 금지 출처 요청 차단](../../audits/2026-10-26_detect_robots_disallowed.md). 조사에 기록된 금지 호스트의 샘플 2건을 요청·다운로드·보존하지 않고 차단 사유와 분모를 유지하는 오프라인 회귀 증거다. 실제 확보율·공개 화면·변경 재처리·출시 완료 증거를 대체하지 않는다.
- P02·P03의 원본 수집·출처 기록 기반 로컬 검증: [Audit 2 리다이렉트·최종 URL·크기·차단 페이지 검증](../../audits/2026-10-26_fetch_redirect_blockpage.md). 루프백 HTTP와 임시 보관소로 다른 출처 이동 및 200 WAF·위장 PDF·초과 응답의 보관 거부, 정상 문서의 최종 URL 기록을 검사한다. 실제 공시 확보율·R2 관측 대조·변경 재처리·출시 완료 증거를 대체하지 않는다.
- P08·P14의 엔진 기반 로컬 검증: [Audit 2 범위 금액 비교의 로드 단계 거부](../../audits/2026-10-26_engine_range_compare_static.md). 합성 규칙 회귀 시험이며 위 표의 실제 데이터·화면·출시 완료 증거를 대체하지 않는다.
- P08의 날짜 조건 계산 기반 로컬 검증: [Audit 2 `date_add` 미지원 키 거부](../../audits/2026-10-26_engine_date_add_unknown_keys.md). 합성 규칙 로더·달력 회귀 시험이며 실제 릴리스 상품 시나리오·화면·출시 완료 증거를 대체하지 않는다.
