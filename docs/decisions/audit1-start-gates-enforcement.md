It should also depend on the node that records confirmed non-Claude access (the Audit 5 node on the D-02 model family), or the supervisor should read decisions_recorded.

**Why:** The gap is real but small, and closing it is cheap. The evaluator already has subset_of, the real_data derive already uses the same shape, and this node's allowed_paths include tools/** and docs/**. Encoding the gate makes the rules file match its own statement that the core reads only cond, and the tests turn 'T-OP-03 cannot start without D-02' into something tested. Making it a stage-4 precondition is moot: stage 4 is already running and only two tasks have a start gate, both also blocked by unfinished deps (T-OP-03: T-KN-06, T-OP-09). The procedure stays because the mock core is a development tool (09 대응표: not part of the release) and does not dispatch work. The supervisor does, and its DEC-D-02 dep is satisfied by the decision record, not by confirmed non-Claude access or D-02 registration. Not critical: this is a reversible change to development tooling with no money, credentials or production path. It makes the system stricter.

**Options:** ['A: Accept the procedural control only and record it (rejected: the finding stays open, the mock core contradicts its own rule that the natural-language when is human-only, and the block rests on memory with no test)', 'B: Make a structured start cond a precondition for stage 4 and stop product dispatch until it lands (rejected: stage 4 is already running, the 61 tasks with start=[] gain nothing, and the two gated tasks are also blocked by unfinished supervisor deps)', 'C: Add the structured cond, mock-core enforcement and tests now, keep the procedure as a second layer, and flag the supervisor dep gap to the operator (chosen)', 'D: Enforce the start gate inside envelope_validator at lease time (rejected: by then the task is already queued and blocked→queued is the wrong transition; envelope validation already covers real_data, and a task should not hold a lease while its start gate is unmet)']
