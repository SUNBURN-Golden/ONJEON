# Audit 7 초기 상품 목록 조회와 ExpectedDocument 후보

작업 `audit7-enumerate-products-first-source` · L0 · M3 · 09 P01/P02

## 실측

- 2026-11-18에 협회 2곳과 원장에 확인된 회사 공시 진입점 8곳을 대상으로 단일 수동 조회를 실행했다. 공시 목록 메타데이터만 읽었다. 회사별 URL과 결과는 [기관 원장](../../../data/registry/README.md#초기-상품-목록-관측-2026-11-18)을 따른다.
- [스냅샷](../../../data/registry/product_discovery.json)은 54개 출처별 조회 범위에서 10개 목록 종료, 1개 부분 관측, 37개 차단, 6개 실패를 기록한다. KLIA는 robots.txt의 전체 금지에 따라 17개 범위를, KNIA는 robots.txt HTTP 403에 따라 19개 범위를 보류했다. 두 협회의 요청은 robots.txt에서 멈췄다.
- 4개 보험사에서 5,213개 상품·특약 관측행과 11,938개 ExpectedDocument 후보를 기록했다. 약관 3,200, 특약 약관 2,412, 사업방법서 5,229, 요약서 1,093, 안내 4개다. 공개 참조를 확인한 행은 10,944개이고 참조 미확정은 994개다. 모든 후보의 원문 확보 상태는 `unqueried`다.
- 흥국화재 판매중지 장기보험은 관측된 225쪽 중 7쪽을 읽었다. 판매중지 일반보험은 본문 읽기 오류, 에이스아메리칸 판매중지 목록은 시간 초과였다. DB손해보험에는 robots 차단, 처브라이프생명·교보라이프플래닛·미쓰이스미토모 한국지점에는 robots 연결 오류를 각각 기록했다.
- 회사 원장의 8곳을 초기 조회 결과와 연결했다. 후보 관측 4곳과 오류 3곳은 기관 전체 목록이 미확정인 `failed`, 전체 접근이 차단된 DB손해보험은 `blocked`로 요약한다. 진입점 미확보 45곳은 `unqueried`다.

## 재현과 판정

`python3 tools/enumerate_products.py --check`는 관측 데이터의 조회 계획, 페이지와 응답 해시의 형식, 문서 역할·행 연결·확보 상태, 회사 원장과의 일치를 검증한다. 공개 페이지는 변경될 수 있다. 당시 본문과 문서는 저장소에 싣지 않았으므로 로컬 검사 범위는 기록과 연결 검증이다. 실행 조건과 로컬 검증 결과는 [실행 증거](../../../tools/evidence/audit7-enumerate-products-first-source/README.md)에 있다.

시험은 협회 조회 형식과 회사 결합, 판매본의 행 병합과 특약 식별, 다음 쪽·반복 쪽·조회 상한, 명시적 빈 목록, robots 정책, 불완전 응답 거부를 재현한다. 09 P01/P02의 전체 분모와 문서 확보에는 아직 협회 목록, 나머지 기관·판매본·특약, 원본 보존과 판 연결 증거가 필요하다. T-DT-04 실데이터 관문 O19를 따른다.
