# Audit 7 접근성 제외 결정 재검토

2026-11-18 | 위임 결정·가역·사용자 확정 아님

[ADR-0021](ADR-0021-첫-출시-최소-접근성.md)과 [BLUEPRINT §7.2](../BLUEPRINT.md#72-방식)에 첫 출시 앱과 공개 웹의 200% 확대·명암 대비·스크린 리더 기준을 반영했다. [09 P19와 작업 계약](../blueprint/proposals/설계검토_결과/09_제품목적_대응표.md)은 실제 화면 검증과 참가자 시험의 담당 및 완료 증거를 정한다.

제3부 §51.4는 사용자 결정이었다. 원래 결정을 공식 교체할지는 [ADR-0021의 사용자 확정 절차](ADR-0021-첫-출시-최소-접근성.md#사용자-확정)로 소유자에게 요청한다. 가역적인 개발 기준은 적용 중이다.

기존 모바일 골격에서 일반 텍스트 대비가 ‘예시로 둘러보기’ 4.47:1, ‘예시 끝내기’ 4.48:1, ‘확인 필요’ 4.14:1이었다. 탭의 시맨틱 노드는 자식 시맨틱을 제외해 활성화 동작이 빠졌다. 수정 1차에서 색 조합, 탭 활성화, 제목과 확대 시 텍스트 배치를 보완했다. 변경 후 회귀 시험과 실제 출시 화면의 잔여 증거는 [실행 기록](../../tools/evidence/audit7-accessibility-out-of-scope/README.md)에서 확인한다.
