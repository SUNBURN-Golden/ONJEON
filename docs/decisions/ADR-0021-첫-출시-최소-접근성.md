# ADR-0021 첫 출시 최소 접근성

2026-11-18 | 위임 기준 수립
2026-11-19 | 소유자 확정

## 맥락

[평가서의 사용자 결정](../review/2026-10-08_Masterplan_v0.3_평가.md#8-평가-이후-결정-2026-10-08)과 [제3부 §51.4](../masterplan/ONJEON_Masterplan_v0.4_제3부_구현계획.md#514-접근성-목표-아님-사용자-결정)는 접근성 기준 마련 권고를 채택하지 않았다. 소비자가 보장·면책·가격 조건을 읽고 설명을 약관 원문과 대조하려면 글자를 확대하고 보조 기술로 같은 경로를 조작할 수 있어야 한다. 제3부 R12가 기록한 고령 사용자 이탈 위험도 이 경로에서 확인한다.

## 결정

첫 출시 소비자 모바일 앱과 공개 웹의 개발·검증 기준을 [BLUEPRINT §7.2](../BLUEPRINT.md#72-방식)에 반영한다.

- 모바일 시스템 글자 크기와 웹 브라우저 확대를 각각 200%까지 적용해 핵심 문구가 잘리지 않고 모든 조작에 도달할 수 있어야 한다. 스크롤로 접근할 수 있다.
- 일반 텍스트는 배경과 4.5:1 이상, 큰 텍스트는 3:1 이상, 조작 요소와 상태를 구별하는 데 필요한 비텍스트 표시는 인접 색과 3:1 이상으로 한다. 큰 텍스트 구분은 WCAG 2.2 정의를 따른다.
- 스크린 리더에서 제목, 조작 요소의 이름·역할·상태, 읽기 순서와 활성화 동작을 확인한다.

기준 근거는 [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/)의 1.3.2·1.4.3·1.4.4·1.4.11·4.1.2와 [Flutter 접근성 시험](https://docs.flutter.dev/ui/accessibility/accessibility-testing)이다.

[BLUEPRINT §7.3](../BLUEPRINT.md#73-대체된-결정-다시-살리지-않는다)이 제3부 §51.4의 제외와 화면·조작 설계서 §0의 제외·시안 변경 제한을 이 개발 기준에 한해 대체한다. 기준을 충족하는 데 필요한 색상·치수·줄바꿈·시맨틱 변경을 허용한다. 변경한 화면과 이유를 작업 증거에 남긴다.

## 완료 증거

[09 §4 P19](../blueprint/proposals/설계검토_결과/09_제품목적_대응표.md)의 완료 증거에 실제 화면의 200% 확대·대비·시맨틱 트리 회귀 시험과 TalkBack·VoiceOver·웹 스크린 리더 실행 기록을 추가한다. T-MB-03은 실제 앱, T-WB-01은 공개 웹을 검증한다. T-UX-01은 PREREG에 고령 참가자 모집·과제 계획을 고정하고 P18의 U7 설명·원문 대조 결과를 기록한다. P18의 판정 기준은 DEC-D-16과 소유자 확인 절차를 따른다. 현재 골격의 로컬 검증 범위는 [Audit 7 실행 증거](../../tools/evidence/audit7-accessibility-out-of-scope/README.md)에 기록한다.

## 사용자 확정

2026-11-19 소유자는 첫 출시 소비자 앱·공개 웹에 한하여 제3부 §51.4의 접근성 제외 방침을 위 기준으로 교체하기로 확정했다. 2026-10-08 결정은 당시의 이력으로 보존한다. 이 확정은 범위 결정이며 구현 완료, P19 실제 화면 검증 또는 출시 승인이 아니다. 소유자 결정과 P19 증거는 기존 T-OP-08 출시 판정에 첨부한다.

## 재검토 조건

확대·보조 기술 시험이나 고령 참가자의 원문 대조 과제에서 보장·면책·가격 조건 또는 원문 접근 실패가 재현되면 해당 경로를 수정하고 출시 전에 재검증한다. 지원 플랫폼이 바뀌면 검증 환경을 다시 정한다.
