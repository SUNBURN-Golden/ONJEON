## 수락 사례의 기록 형식

각 사례는 ID, 요구 ID, 원문/합성 구분, 입력, 기대 상태·결과·화면, 금지 결과, 사용한 버전, 실행 결과를 가진다. 문서·코드의 '테스트 추가 예정'은 통과가 아니다.

예: `AC-R11-01` — 연납 120,000원만 있는 합성 상품. 기대: 월평균 10,000원 표시 또는 월납 미공개. 금지: 월납 보험료 10,000원으로 저장·다른 월납 가격과 무표시 정렬. 이 숫자는 실제 보험 데이터가 아니다.

예: `AC-R21-01` — 본문 불변, 참조 별표의 제외 질환만 변경. 기대: 참조 담보 후보 릴리스 재검증, 구버전 계약 바인딩 보존, 영향 계산의 버전 분리. 금지: 변경 없음 처리.

## 완료 보고 규칙

설계/구현/합성 검증/실제 원문 검증/사용성 검증/운영 검증을 각각 기록한다. CI 성공은 그 CI에 들어간 코드 검사만 통과했다는 뜻이다. 실제 상품·보장·가격 정확도와 소비자 이해를 대신하지 않는다.
