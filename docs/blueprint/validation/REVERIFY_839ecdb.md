## 그대로인 한계

- 화면 숫자는 구조화 필드에서 **생성**하지 않고, 화면 문구의 숫자가 지정한 필드 값과 같은지 **대조**한다. 문구 생성기는 아직 없다.
- 실제 S3 보존과 다운로드 대조는 자격 증명이 없어 하지 못했다. 사용자에게 전달한 묶음의 복원은 사용자가 확인해야 한다.
