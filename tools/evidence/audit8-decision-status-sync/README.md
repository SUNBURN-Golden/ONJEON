# Audit 8 결정 상태 동기화

작업 트리에서 확인한 DEC 원문은 22개다. [결정 원장 §3.1](../../../docs/blueprint/DECISIONS.md#31-결정-게이트-기록-dec-)의 기록과 작업별 관문을 사용해 `tasks.json`의 `decision_index`, [README §6](../../../docs/blueprint/proposals/설계검토_결과/README.md), 03 §5, [09 P01~P19](../../../docs/blueprint/proposals/설계검토_결과/09_제품목적_대응표.md)의 결정 상태를 생성한다. 색인의 24개 항목은 DEC 원문 22개와 O16·O19다. O19는 기존 T-DT-04의 실데이터 관문이다.

D-12의 소유자 결정은 소비자 앱에서 원문 이미지·발췌를 표시하도록 허용했다. O16은 그 범위의 해결과 공개 저장소의 새 발췌 추가·재배포 조건을 함께 기록한다. 앱 표시 플래그와 D-12 관문 등록은 별도다. D-09·D-10·D-15는 감리 대기 상태이며 O03의 사전 내용은 미정이다. [DEC-D-12](../../../docs/decisions/DEC-D-12.md).

재생성은 `python3 -I tools/decision_status.py --write`, 정합성 검사는 `python3 -I tools/decision_status.py`를 실행한다. 이번 변경의 검증은 결정 문서·과제 역색인에 대한 증거이며 첫 출시 완료는 09의 실제 제품 증거로 판정한다.

임시 복제본에서 D-12 상태를 미정으로 바꾸고 O19 색인을 지운 뒤 세 Markdown 표에 이전 문구를 넣었다. 검사 명령이 네 파일의 불일치를 감지했고 재생성 후 네 파일이 작업 트리의 결과와 바이트 단위로 일치했다. 기준판과 대조한 과제 정의 67개, 기능 증거 항목 64개, 09의 완료 증거·추적 열 19개도 일치했다. [실행 기록](verification.log).
