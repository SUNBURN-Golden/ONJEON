## 5. 검증하지 않은 것

- T02~T04는 규칙 파일·문서·시험 명세가 서로 맞는지까지만 확인했다. 아래 항목은 실행으로 증명되지 않았다. 모의 코어(T-OP-00)와 실제 실행기(T-OP-09)가 아직 없기 때문이다.
  - tree OID 일치
  - 각 실패 상황에서 복구 가능한 상태로 멈추는지
  - 자격 회수가 실제로 집행되는지
  - 발급 트랜잭션의 원자성과 outbox 복구
  - envelope_id 생성
- T01은 토의 자료 검증기 수준의 동작 검증이다. 서비스 입력 단계(T-TW-01)는 설계 단계다.
- 판이 확인된 다른 특약을 무관하다고 보는 근거는 "담보는 한 판에만 정의된다"는 것이다. 다른 판이 그 담보에 조건을 덧붙이는 관계(attached_to 등 구성·종속 관계)는 이 검사 범위 밖이다.
- 설계 담당과 구현자는 둘 다 claude 계열이다. 검사기도 구현자가 썼다.
