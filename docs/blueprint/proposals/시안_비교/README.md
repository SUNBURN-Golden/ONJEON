# 같은 상황으로 비교: 화면 시안 (21~23차, 23차 판으로 잠정 고정, 토의 자료)

> 이 폴더는 **토의 자료**입니다. 설계 결정이 아니고, 구현 범위나 계약 문서에 반영하지 않았습니다.
> 표기: **진행 지시(사용자)** · **토의상 제안(사용자)** · **검토 의견(구현자)**

- `비교_시안.html`: 단독으로 여는 화면 시안(390px 한 화면).
- `검증/run.js`, `검증/결과.txt`: 자동 실행 검증과 그 결과.
- `캡처/`: 기본, 가입 후 2년, 전체 조건과 현대해상 근거를 펼친 상태(23차 판).

## 1. 이번 차수에 받은 지시와 제안

**진행 지시(사용자)**
- 세 화면(A·B·C)은 일단 확정하고 비교 화면으로 넘어간다. 사용자 시험은 나중에 하며, 이번 단계의 전제가 아니다.
- A와 C를 구분하는 일은 나중에 진입 제목('상황을 가정해 보기' / '내 사건 확인')으로 처리한다. 지금 세 화면을 다시 고치지 않는다.
- 차이가 분명한 상품을 3개쯤 고른다. 확인된 실제 자료만 쓰고, 모르는 것은 모른다고 표시한다. 보험료나 금액을 지어내지 않는다.
- 9개 보험사 126개는 우선 **"확보한 공시에서 찾은 비교 후보"**로만 본다. 서로 다른 상품인지, 같은 기준으로 비교할 수 있는지는 따로 확인해야 한다. 담보명에 '암 진단'이 들어 있다고 같은 보장으로 묶지 않는다.

**토의상 제안(사용자): 비교 화면 구성**
- 먼저 보여 줄 것: "같은 상황을 넣었을 때 무엇이 같고 무엇이 다른가".
- 맨 위: 상황과 공통 가정(진단 상황, 가입 후 경과 기간, 최초 진단 여부). 짧게, 바꿀 수 있게.
- 상품마다 같은 자리에: 계산한 금액, 또는 계산하지 못한 이유. 가입금액을 지급액처럼 보여 주지 않는다.
- 차이를 나란히: 지급 대상, 제외, 감액 기간, 갱신 여부.
- 보험료: 조건이 같을 때만 바로 비교한다. 다르면 공시마다 조건을 붙인다. '최저가' 표시와 가격순 정렬은 하지 않는다.
- 근거 조항과 전체 조건은 접는다. 결과를 바꾸는 조건은 금액 가까이에 둔다.
- 비교 화면에서 상황 → 금액 → 중요한 차이 → 근거 순서로 잘 읽히는지 확인한다.

## 1-2. 22차: 금액의 근거 기준 맞추기

**진행 지시(사용자)**
- 화면 배치보다 먼저, 하나손보의 500만·1,000만 원을 어떤 의미로 보여 주는지 바로잡는다. 롯데처럼 약관을 확보하지 못했고 감액 기준일도 미확인이므로, "위암 진단 시 계산 결과"로 표시할 근거가 충분한지 다시 본다.
- 공시의 50%로 산술 계산은 할 수 있어도, 그 규칙이 이 상황에 적용되는지는 별개다. 적용을 확인하지 못했다면 "공시된 감액률을 적용한 예시"로 구분한다.
- 현대해상의 '-'를 감액 없음으로 읽은 것도 해석이다. 특약 본문과 표의 주석까지 맞는지 확인한 뒤 결과에 쓴다. 세 상품 모두 같은 확인 기준을 적용한다.
- 담보 가입금액을 1,000만 원으로 맞춰 비교한 것인지 공통 조건에 밝힌다. 공시 보험료의 담보 구성이 이와 다르면, 보험료 옆에서 "위 보장 구성의 견적이 아님"이 읽혀야 한다.
- "공시에 없음"은 "확인한 공시에 기재 없음"으로 쓴다.

**토의상 제안(사용자): 21차에서 남긴 네 가지 의문에 대한 답**
- 휴대폰의 차이 표: 항목별로 세 상품을 세로로 나열한다. 먼저 현재 상황에서 금액을 가르는 차이를 보여 주고, 전체 조건은 펼쳐서 보게 한다.
- 2년을 고를 때 감액 안내: 규칙은 남기고 현재 적용 여부만 바꾼다. "선택한 2년 시점에는 해당 없음"처럼 단정하는 문장은 적용 기준이 확인된 경우에만 쓴다.
- 계산 보류 상품: 같은 목록에 둔다. 빼거나 뒤로 보내면 자료가 많은 상품이 유리해진다. 보류 이유와 확인된 조건은 그대로 보여 준다.
- 출처 표시: '약관'과 '공시'를 작게 표시하되, 출처의 종류와 이 상황에 적용되는지는 구분한다.
- 이번 시안의 핵심: 확인된 차이는 쉽게 보여 주고, 자료가 부족하다는 사실이 상품의 단점처럼 보이지 않게 한다.

**반영 내용 (검토 의견(구현자). 시안에서 쓴 방식이며 확정이 아님)**

세 상품에 같은 네 가지 확인 항목을 적용했습니다.
- 위암이 지급 대상인가
- 진단일이 보장 시작 이후인가
- 진단 시점에 감액이 적용되는가
- 얼마를 지급하는가

| 금액 위 표시 | 조건 | 해당 상품 |
|---|---|---|
| 약관 기준 계산 | 네 항목을 모두 약관 본문으로 확인함 | 현대해상 |
| 공시 감액률을 적용한 예시 | 공시 문구상 지급 대상에 들지만, 약관으로는 네 항목을 확인하지 못함 | 하나손보 |
| 계산 보류 | 공시 문구만으로는 위암이 지급 대상인지 판단할 수 없음 | 롯데손보 |

- 하나손보와 롯데손보는 둘 다 약관을 확보하지 못했습니다. 둘을 가른 것은 공시 문구가 이 상황까지 닿는지 여부입니다.
  - 하나손보: 공시가 "암"에서 무엇을 빼는지 적어 두었고, 위암은 빠진 목록에 없습니다.
  - 롯데손보: '일반암'의 범위가 공시에 적혀 있지 않습니다.
  - 이 경계선은 제가 정한 것이라 토의가 필요합니다. 더 엄격하게 하면 하나손보도 계산 보류가 됩니다.
- 현대해상은 다시 확인했습니다. 확인한 파일은 약관 PDF, sha256 9401e98e…입니다.
  - 지급금액: 305쪽 제1조의 지급금액은 "이 특약의 보험가입금액"이고, 금액을 줄이는 문구가 없습니다.
  - 지급 대상: 제2조①과 1223쪽 별표2에서 위암(C16)은 소화기관(C15~C26)에 속합니다. 유사암(C44, C73, 제자리암, 경계성종양)이 아닙니다.
  - 보장 시작: 제3조①에 따라 계약일부터 90일이 지난 다음날입니다.
  - 감액 규정: 특약 본문(305~306쪽)과 보통약관(125~154쪽)에서 '감액'을 검색했습니다. 보험료 감액과 가입금액 감액만 나오고, 진단금을 줄이는 규정은 없었습니다.
  - 지급제한표(117쪽): 이 특약의 '1년미만 보험금 감액여부'는 '-'입니다. 같은 표의 119~121쪽 행에는 50% 같은 비율이 적혀 있습니다. '-'의 뜻을 설명하는 주석은 없습니다.
  - 그래서 "감액 없음"은 표의 '-'가 아니라 특약 본문을 근거로 씁니다.
  - 확인하지 못한 것: 진단확정 요건(제2조⑦)을 갖췄는지, 계약 전 알릴 의무 같은 실제 계약 사정. 이 둘은 근거 칸에 적었습니다.
- 공통 가정에 "세 상품 모두 암 진단 담보 가입금액을 1,000만 원으로 맞춤"을 적었습니다. 세 공시의 예시 가입금액이 모두 1,000만 원입니다.
- 보험료 쪽 반영:
  - 상품마다 "위 보장 구성의 견적이 아님"을 붙였습니다.
  - 각 보험료가 공시가 정한 담보 묶음의 예시라는 점도 적었습니다(롯데: 기본계약과 주요특약, 하나: 담보 13개, 현대: 주요특약).
- 차이는 항목별 세로 나열로 바꿨습니다.
  - 기본으로 보이는 것: 지급 대상, 가입 초기 감액, 보장 시작.
  - "전체 조건 보기"를 펼치면 보이는 것: 갱신, 따로 보는 암, 지급 횟수.
  - 값마다 출처 꼬리표('공시' 또는 '약관')를 달았습니다. 이 상황에 적용되는지는 금액 위 표시로만 나타냅니다. 두 가지가 다르다는 점을 안내 문구로 적었습니다.
- 하나손보의 감액 규칙 "1년 미만 50% 감액"은 8개월과 2년 모두에서 그대로 보입니다.
  - 바뀌는 것은 적용 여부 문장뿐입니다("이 예시에 적용했어요" / "이 예시에는 적용하지 않았어요").
  - 기준일을 확인하지 못했으므로 "해당 없음"이라고 단정하지 않았습니다.
- 롯데손보 반영:
  - 같은 목록, 같은 자리에 두었습니다.
  - "계산 보류" 글자는 다른 근거 표시와 같은 회색이고, 강조색을 쓰지 않았습니다.
  - 21차에 있던 "일반암에 든다면 500만 원"이라는 조건부 금액은 뺐습니다. 금액처럼 읽힐 수 있어서입니다. 그 대신 확인된 조건(가입금액 지급, 계약일부터 1년 미만이면 50%)만 남겼습니다.
- "공시에 없음"은 모두 "확인한 공시에 기재 없음"으로 바꿨습니다.

## 1-3. 23차: 대표 결과와 산술 예시 분리, 시안 잠정 고정

**진행 지시(사용자)**
- 하나손보의 금액은 위암 상황 비교의 대표 금액으로 놓기 어렵다. 제외 목록에 위암이 없다는 것만으로는 지급 대상이라고 확인할 수 없다. 하나와 롯데 모두 이 상황의 지급액은 미확인으로 두고, 하나의 "1년 미만 50% 감액" 공시 정보는 그대로 비교한다.
- 하나의 500만 원을 남기려면 근거를 펼쳤을 때 이렇게 보여 준다: "가입금액 1,000만 원에 공시된 감액률 50%를 적용하면 500만 원입니다. 이 위암 상황에 해당 규칙이 적용되는지는 아직 확인하지 못했습니다."
- 현대의 '약관 기준 계산'에도 이 시나리오의 전제를 붙인다(예: 약관상 진단 요건을 충족한 최초 진단). 그 가정이 실제 계약에서 확인됐다는 뜻으로 넘어가면 안 된다.
- 현대: 명시한 가정에 따른 약관 기준 계산. 하나·롯데: 이 상황의 지급액 확인 필요. 함께 보여 줄 것은 확인된 조건과 근거다.
- 이 기준만 바로잡고 비교 시안을 잠정 고정한다. 새 표시나 설명을 계속 늘리지 않는다.

**반영 내용**
- 금액 표시
  - 큰 금액 자리에는 현대해상 1,000만 원만 남겼습니다.
  - 하나손보와 롯데손보는 같은 자리에 "이 상황의 지급액 확인 필요"를 같은 회색 글씨로 적었습니다.
  - 그 아래에는 각 상품의 이유와 확인된 공시 조건을 두었습니다.
- 하나손보 500만 원
  - 하나손보 근거 칸의 "산술 예시"에만 넣었고, 위 문장을 그대로 썼습니다.
  - 첫 화면에는 500만 원이 나오지 않습니다. 자동 검사로 확인했습니다.
- 공통 가정
  - 기존 "처음 받는 진단금"을 "약관상 진단 요건을 충족한 최초 진단이라고 가정"으로 바꿨습니다.
  - 현대해상 아래에 "위의 공통 가정에서 계산했어요. 실제 계약에서 확인한 것은 아니에요."를 적었습니다.
  - 현대해상 근거에 "계산 전제(가정)"를 두었습니다.
- 경과 기간 전환
  - 이제는 진단일만 바뀝니다. 금액이 확인되지 않은 상품에 금액이 생기지 않기 때문입니다.
  - 하나손보의 감액 조건은 두 시점 모두에서 그대로 보입니다.
- 22차 1-2절의 "공시 감액률을 적용한 예시" 등급과, 하나·롯데를 가른 기준은 이번 차수로 대체되었습니다.

**검증**
- 42개 항목을 확인했고 실패는 0건입니다. 결과는 `검증/결과.txt`에 있습니다.
- 사용자 시험은 하지 않았습니다.

**잠정 고정.** 이 판으로 비교 시안을 멈춥니다. 표시나 설명은 더 늘리지 않았습니다.

**같은 차수에 받은 제안.** 미확인을 줄이는 흐름(정보 공백 발견 → 외부 문의 → 회신 확보 → 검수 → 반영)은 [공개지식 모델 토의초안 §12](../공개지식_모델_토의초안.md)에 토의상 제안(사용자)으로 기록했습니다. 실제 문의를 보내지 않았으므로 화면에 "보험사에 확인 중"은 넣지 않았습니다.

## 3. 126개 후보 수치에 대한 정정
