# 설계 책임 인계 자료: Fable(불가 시 GPT Astra)

작성 2026-10-12 | 인계하는 쪽: 이 세션의 구현자(토의 자료·조사·시안 작성자) | 받는 쪽: 전체 코드 설계·구현 계약 담당 Fable, 사용할 수 없으면 GPT Astra(사용자 결정 2026-10-12)

> **인계 상태(정직하게).** 이 문서와 링크된 자료가 인계 묶음이다. **Fable이 이 묶음을 실제로 받아 검토를 시작한 것은 아니다.** 이번 작업에서는 이 세션에서 Fable에게 최소 연결 확인 요청 한 번만 보냈다. GPT Astra는 이 환경에서 연결을 확인하지 못했다([자동 개발 설정안](../자동개발_설정안/README.md) §4).
>
> **갱신(2026-10-12, 사용자 지시 후).** 이 세션에서 설계 담당 역할(Fable)로 지정한 하위 에이전트가 이 묶음과 온톨로지 검증 결과를 읽고 설계 검토 결과물을 제출했다: [설계검토_결과/](../설계검토_결과/README.md)(검토 대상 SHA 4549fd0). 자기 보고 모델명은 증명이 아니다. 작성 계열 밖 독립 리뷰는 아직 없다. 이 결과물은 채택된 정본이 아니다.

## 7. 알려진 함정 (이번 토의·조사에서 실제로 겪은 것)

- **요약서를 확인된 조건처럼 보이면 ADR-0014와 충돌한다.** 24차 시안에서 생겼고 25차에 정정했다.
- **"계산 보류"와 "산술 예시"를 대표 금액 자리에 섞으면** 지급액 비교로 읽힌다. 23차에서 분리했다.
- **목록에 없음 ≠ 판매 종료, HTTP 200 ≠ 성공, 상품명·코드 ≠ 식별자**(조사 H1·H5·H7).
- **robots를 확인할 수 없는 호스트는 수집을 보류한다.** 롯데손보 HTTPS는 연결이 재설정됐고 HTTP robots는 시간 초과됐다(I 기록 §3).
- **원문 사본은 세션 임시 영역에만 있다.** 이 컨테이너가 회수되면 사라진다. R2 보존은 별도 승인(D-04)이 필요하다.
- **저장소가 public이다.** 원문 발췌의 추가 공개는 O16 결정 전에 하지 않는다.
- **이름이 같다고 같은 질병 분류가 아니다.** 하나손보와 현대해상의 "암"은 코드 집합이 다르다. 범위 관계는 코드로 계산하고, 계산할 수 없으면 승인하지 않는다(온톨로지 K12).
- **자기 보고 모델명은 증명이 아니다.** 실행 기록에는 실행 경로의 설정값을 남긴다.

## 8. 받는 쪽에게 요청하는 첫 검토 (구현 계획 §16과 같음)

1. 코드 구조와 구역 경계(구현 계획 §12)가 전 기능을 담는지
2. 구역 간 계약 목록(§13)의 빠진 것과 버전 정책
3. 작업 묶음과 의존관계(§14), 특히 디지털 트윈 관련 묶음의 순서
4. PR별 완료 기준(§14)이 "시안·픽스처를 완성으로 세지 않음"을 지키는지
5. 감리 지점(§15)
6. 구현자 선택으로 분류한 결정(통합안 §8.3)에 대한 선택안
7. 온톨로지 설계안의 개념·관계·제약과 책임 경계, 설계안 §12의 설계 담당 선택 항목(구현 계획 §16의 7)

검토 결과는 정본을 고치지 않고 이 폴더에 `검토_결과_<날짜>.md`로 남긴다. 정본 반영은 사용자 지시가 있을 때 ADR로 한다.
