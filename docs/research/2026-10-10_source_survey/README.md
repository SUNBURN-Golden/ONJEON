# 2026-10-10 공시 출처 조사

상태: **토의 자료(관측 기록)**. 설계 결정이 아니다. 이 조사를 근거로 한 [수집·지식 기반 설계 제안](../../blueprint/proposals/수집_지식기반_설계_제안.md)도 미확정 토의 자료다.

## 목적

수집·지식 기반 설계(ADR-0018 이후 토의 2번)에 앞서, 한국 보험 공시가 실제로 어떻게 생겼는지와 예외를 확인한다. 특히 "판매본 = 회사 + 상품 + 약관 적용 기간"이라는 정의가 실제 공시에서 성립하는지 확인한다(사용자 지시: 임시 정의를 채택하지 않고 조사로 확인).

(ADR-0018은 PR #3 초안에 있고 아직 main에 없다.)

**표본 조사는 서비스 범위를 줄이지 않는다.** 포함 범위는 ADR-0018대로 보험사의 개인보험 전 상품·전 특약·과거 판매본과 우체국보험이다.

- 조사 그룹 6개를 병렬로 돌렸다. 기관은 회사 수가 아니라 **공시 구조의 다양성**으로 골랐다.
- 모든 그룹이 같은 가설 14개(H1~H14)를 지지/반례/판단 불가로 판정했다(아래 표).
- 수집 규칙: 공개 페이지만, 로그인·본인인증·개인정보 입력 없음, robots.txt를 먼저 받고 금지 경로는 요청하지 않음, 요청 간격 2초 이상, 그룹당 요청 250건·큰 PDF 10개 이하, 한 호스트에서 3회 연속 실패하면 중단.
- 관측·규정상·2차·추정을 구분해 적었다.
  - **관측**: 받은 파일에서 직접 확인

  - **2차**: 1차 호스트에 접속하지 못해 미러나 제3자 자료로 확인

## 보존 상태

**원문 사본은 영속 보존되지 않았다.** 이 항목이 끝나기 전에는 조사 기록의 원문 근거가 재현 가능하다고 보고하지 않는다.

| 대상 | 위치 | 상태 |
|---|---|---|
| 조사 기록(이 폴더의 .md) | Git 저장소, 토의 자료 전용 브랜치 `claude/source-survey-2026-10-10`(PR #3과 분리) | 원격에 푸시하면 영속. **보존은 설계 채택이나 구현 승인을 뜻하지 않는다** |
| 요청 로그(URL, 시각, 상태, 파일명, sha256) | [requests/](requests/) | 같은 상태. 비밀값이 없음을 확인했다(키·토큰·쿠키 값 없음) |
| 원문 사본(HTML·JSON·PDF·HWP·ZIP 등 393개, 약 200MB, 대조용 RFC 9309 원문과 robots 2개 별도) | 세션 임시 영역(`scratchpad/survey/<그룹>/raw/`) | **임시.** 이 컨테이너가 회수되면 사라진다 |
| 추출 텍스트·파싱 결과·조사 스크립트 | 세션 임시 영역 | **임시** |

원문을 Git에 넣지 않은 이유: 공시 원문의 재배포 범위가 정해지지 않았다(ADR-0015: 원본은 비공개 보관소에 두고, 보존이 재배포 허가는 아니다).

R2 비공개 보관소에 넣지 못한 이유(저장 권한 부족):
1. 세션의 R2 자격 증명을 지웠다(대화에 노출된 토큰은 폐기 대상).
2. 비용 한도 작업 파일은 고정 119키의 업로드·대조만 허용한다(D18). 새 원본을 올리려면 새 작업 파일과 승인이 필요하다. 대량 자동 수집은 별도 관문(O17)이다.

영속 보존에 필요한 것(실행 권한, 설계 제안 §10 X1):
- 범위를 좁힌 새 R2 토큰을 환경 비밀값으로 제공
- 조사 원문용 고정 키 작업 파일 승인(조사 원문 393개 + 대조용 2개, 약 200MB, 수동 1회 실행)

그 전까지 요청 로그의 sha256으로 나중에 다시 받은 파일이 같은지만 확인할 수 있다. 공시가 그 사이에 바뀌면 이번 관측의 원문은 복구할 수 없다.

## 절차 고지

- **A 그룹, pub.insure.or.kr**: robots.txt가 `User-agent:* Disallow:/`인데, robots.txt를 받은 같은 명령 안에서 그 내용을 확인하기 전에 첫 화면 `GET https://pub.insure.or.kr/` 1건이 나갔다(02:38:38Z, [requests/A_klia.tsv](requests/A_klia.tsv) 머리글 포함 3행). 이후에는 robots.txt 외 요청이 없다. A_klia.md §2.1은 이 1건에 근거한다. 이 사본을 보존·인용할지는 제품 선택 문제다(설계 제안 §10 C5).
- **원문 대조로 고친 것**: F의 판매 목록 제출 근거, A의 자사코드 문구 위치, D의 삼성화재 같은 파일 URL 수(4개 → 받은 3개), D의 현대해상 두 행 판단(중복 → 판단 불가). 자세한 내용은 [근거 구분](근거_구분.md) §4.
- **E 그룹, 2차 출처**: 우체국보험 사이트·law.go.kr 일부가 연결 리셋으로 막혀 공개 미러(legalize-kr, GitHub 저장소)를 썼다. 1차로 확인하기 전까지 사실로 단정하지 않는다.
- 조사 요청은 이 Claude 클라우드 환경에서 해외 IP를 거쳐 나갔다. 국내 IP에서는 접근 결과(WAF 차단, 연결 리셋)가 다를 수 있다.

## 설계 쟁점으로 넘긴 것

조사에서 나온 것 중 구현자가 정하면 안 되는 것은 설계 제안 §10으로 넘겼다. 성격에 따라 셋으로 나눴다.
- **조사로 해결할 문제(R1~R12)**: 이용약관·저작권 표시, 금감원 자료, 접속 실패 회사, 우체국 고시 연혁, 가격 공시, 과거 판 법령, 요약으로만 본 보도자료 원문, 사례 판단용 문서 등
- **제품 선택이 필요한 문제(C1~C10)**: 생보협회 robots 금지 경로의 대안, 403·WAF 호스트 수집 여부, 원문 사본 공개 범위, 판매 구성 단위 등
- **실행 권한이 필요한 문제(X1~X3)**: 원문 영속 보존용 R2 토큰과 작업 승인, 대량 수집 관문(O17), 국내 실행 환경
