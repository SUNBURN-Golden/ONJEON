## 4. 이 표가 말하지 않는 것

- 어느 행도 "완료"가 아니다. 상태 열의 "구현됨"은 기존 엔진·도구에만 해당한다.
- 행의 과제 집합은 최소 경로다. 전체 완성품의 조건은 tasks.json `feature_registry`(64개 항목, 각각 tasks·evidence·acceptance_tests)와 T-OP-08 판정기(release-readiness-rejects-incomplete)가 검사한다.
- 축 2(실제 데이터 확보)·축 4(사용자 이해)·축 5(운영 준비)의 수치는 실측 전이다.
