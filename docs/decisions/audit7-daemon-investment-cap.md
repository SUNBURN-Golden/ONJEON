# Decision: T-OP-09 is done and the daemon is about half the code. Freeze `tools/daemon` to maintenance and poin

Decided by Claude Sonnet 5.5 xhigh (ONJEON autoloop, 2026-11-18 09:29 KST); reversible.

**Decision:** Audit 6에서 정한 유지보수 동결을 확정한다. tools/daemon의 신규 기능·리팩터링·일반 하드닝을 중단하고, 재현된 작업 유실·중복 실행·관문 우회·보안 결함만 최소 수정과 회귀시험으로 처리한다. 에이전트 역량은 V1의 파생물 6건 재생성, 실제 이종 계열 검수, 화면 설계 항목 S1·S6 해결에 우선 배정한다. V1 통과 후 병합된 T-CT-01/04/05, T-OP-01, T-DT-01을 재사용해 M1의 I7·I12 검증을 마친다. 이어 기존 T-KN-04 브랜치를 최신 기준에서 재검증하고 최종 SHA의 독립 리뷰와 CI를 거쳐, T-OP-02의 실제 공시 원문→주장·검수→트윈 계산→소비자 화면→원문 좌표 연결과 보류·그림자 비교 증거를 확보한다.

**Why:** HEAD 1dfc60b에서 T-OP-09의 #98 병합과 VM 보고서의 PASS 17·PARTIAL 5·FAIL 0을 확인했다. Audit 6 동결 결정 #556 이후 tools/daemon 변경은 0건이다. 데몬은 테스트·생성물·증거를 제외한 지정 소스 행 기준으로 데몬과 packages/services/apps 합계의 41.2%, infra와 기타 tools까지 포함하면 29.1%다. 우선순위는 코드 비중보다 제품 관문으로 판단했다. T-KN-04 브랜치 674f333은 현재 HEAD에 미병합이며, 브랜치의 마지막 인계 기록에도 최종 SHA의 독립 리뷰와 원격 CI 확인이 남아 있다. 관련 읽기 전용 회귀시험 25개와 제품목적 등록 검사가 통과했다. 확대 시험 중 37개는 읽기 전용 환경에서 임시 디렉터리를 만들 수 없어 실행이 막혔다. 저장된 V1 보고서는 8/14 재현이며 현재 재생성기도 나머지 6건에 no_regenerator를 반환했다. 출시 판정기를 재실행한 결과 09의 P01~P19 전부와 기능 64개가 열려 있다. 이번 결과는 개발 우선순위 결정과 읽기 전용 검증이다.

**Options:** ['채택. 데몬 유지보수 동결을 유지하고 V1 → M1 → S1 제품 검증 순서로 역량을 배정한다.', '기각. T-OP-09의 PARTIAL을 모두 해소할 때까지 데몬 투자를 계속한다. 제품 작업에서 이 기록을 선행으로 요구하는 곳은 T-OP-08 최종 감리뿐이다.', '기각. 지정된 여섯 과제를 즉시 착수한다. 다섯 건의 병합 작업이 중복되고 V1 관문을 건너뛰게 된다.']
