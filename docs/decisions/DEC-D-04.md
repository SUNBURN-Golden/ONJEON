## 적용 범위 (Scope: D16~D18 유지)

- **바뀌는 점:** 대화에 노출된 R2 토큰을 폐기하지 않는다(토큰 폐기 미수행).
- **그대로 유지되는 R2 운영 원칙 (`D16`~`D18`, ADR-0016·ADR-0017):**
  - `D16` (ADR-0016): 원본(`onjeon-raw-sources`)·파생(`onjeon-derived-sources`) 버킷 분리, SHA-256 경로, 조건부 쓰기(`If-None-Match: *`)를 통한 덮어쓰기 금지, 삭제 명령 없음, 비공개 유지, 개인 계약·건강·가족력·DNA 자료 저장 금지, 무기한 잠금 금지 및 승인 전 잠금 금지.
  - `D17` (ADR-0017): 대량 수집 전 비용 제한(실행별 제한 + `onjeon-budget-ledger` 원장 누적 사용량 기반 폭주 완화 장치), 실행 전 바이트·요청·재시도·실행 시간 제한, 한도 소진·원장 조회 실패 시 중단, 작업 파일 없는 R2 호출 금지.
  - `D18` (ADR-0017): 지정 실행 환경 하나, 동시 실행 1개, 수동 실행만 허용. 대량 자동 수집은 별도 관문(`O17`) 통과 전까지 차단.
- **절차적 경계:** 비밀값(실제 토큰 문자열)은 저장소·문서·로그·봉투 어디에도 기록하거나 출력하지 않는다. 이 PR은 `docs/decisions/DEC-D-04.md` 한 파일만 기록하며 다른 파일은 변경하지 않는다.
