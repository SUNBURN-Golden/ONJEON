# 세 흐름 시각 시안 원본 사본

상태: **토의 자료. 미확정.** 2026-10-11(17차 반영)

- **가상 계약·가상 사건으로 만든 화면 예시다.** 실제 개인 자료가 아니다. 숫자는 가상 계약과 약관 조항으로 손으로 계산한 예시이며, 계산 엔진과 연결되지 않았다.
- 원본은 Design 캔버스 시안(https://claude.ai/artifact/DuB8aN9HtPJY5ECetSCTKu, 비공개)이다. 이 폴더는 그 파일의 사본이다.
- **독립 실행되지 않는다.** 각 `.dc.html`이 불러오는 `support.js`는 캔버스가 제공하는 실행 파일이다. 이 저장소에는 없다. 이 사본은 보관과 대조용이다.
- 색과 구성은 [화면 조작 설계서](../../../design/화면_조작_설계서.md) §3.1의 시안 실측 토큰을 따른다(배경 #F6F4EE, 글자 #1A1411·#66554A, 테라코타 #AE583F·#A14529, 구분선 #E3DED5, 세그먼트 #EDE8E1·#E8D9CD).

## 어디까지 눌러 볼 수 있나

| 화면 | 동작함 | 연결 안 됨(누르면 아무 일 없음) |
|---|---|---|
| A 이런 일이 생기면? (`Main.dc.html`) | 일반 암 / 제자리암 등 / 갑상선암 전환, "실제로 진단받았어요"(→C), "내 보험 보기"(→B) | 예시 조건 "바꾸기", "적용 조건 보기", "자세히" |
| B 내 보험 (`B_summary.dc.html`) | "아직 모르는 것" 펼치기·접기, "이런 일이 생기면?"(→A), "이 일이 생겼어요"(→C) | "계약 변경·서류 추가", 특별조건 "보기", "유지 중이에요"·"해지·실효된 적 있어요" |
| C 이 일이 생겼어요 (`C_result.dc.html`) | "받은 적 없어요"·"받은 적 있어요", 받은 진단금 고르기, "보험별 내역"·"계산에 쓴 정보" 펼치기 | "고치기"(계산에 쓴 정보 안), "자세히", "보험금 청구 준비", "납입면제 요청 안내" |

화면 사이 이동(→A, →B, →C)은 캔버스의 재생(Play)에서만 된다.

## C의 "받은 진단금 빼기"에 대해
- 받은 진단금을 고르면 그 보장을 빼고 합계를 다시 보인다. 이것은 이 사례의 세 특약(암진단Ⅱ, 암진단Ⅱ(갱신형), 보험료납입면제대상)이 약관상 최초 1회만 지급되는 규칙을 화면에서 보여 주는 예시다. 일반 계산 규칙이 아니다.
- "받은 적 있어요"를 누르고 아직 아무것도 고르지 않았으면, 금액 대신 "어떤 진단금을 받았는지 확인 중이에요"를 보인다.
