# ADR-0004 대상 범위: 전 보험사·전 상품, 이용 등급에 따른 단계 공개

상태: 확정(사용자 결정) | 날짜: 2026-10-08 | 근거: 제3부 §43

## 맥락

v0.3은 첫 보험군을 정액형 진단 담보, 보험사를 3곳으로 가정했다. 사용자는 대상을 모든 보험사의 모든 보험(실손·간병 포함, 모든 특약)으로 확정했다.

## 결정

1. 대상은 국내 모든 보험사의 모든 상품, 모든 주계약과 특약이다. 판매 중지 상품도 기존 계약 매칭을 위해 포함한다(가정).
2. 수집·색인·원문 연결은 대상 전체에 적용한다.
3. 계산·비교는 담보 발생본마다 이용 등급이 승인된 것부터 켠다. 미승인 담보는 원문 보기까지만 제공하고 "아직 계산하지 않아요"로 표시한다.
4. "빠짐없이"는 분모(§23)와 층별 확보율로 증명한다. 증명 전에는 "전수"라고 표시하지 않는다.
5. 공개 순서는 웨이브(W1 정액형 → W2 정액 확장 → W3 실손 → W4 간병 → W5 배상·재물·자동차 → W6 저축·연금·변액)로 관리한다. 웨이브는 일정 순서이며 범위 축소가 아니다.

## 결과와 위험

- 검수 처리량이 전체 일정을 정한다. 발생본 수를 분모 조사로 먼저 알아야 하고, 완료 시점은 그 뒤에 추정한다(제3부 §54.3).
- 실손·저축성은 계산 구조가 달라 엔진 연산을 추가해야 한다(제3부 §49.2, R13).
- 불변 원칙 3·5·7은 범위와 무관하게 유지한다. 범위가 넓어도 미검증 담보를 추정이나 0원으로 계산하지 않는다.
