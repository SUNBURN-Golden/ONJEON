## 보험기간 구분과 기간별 보험금

```text
[PDF p.4]
문 : 교보K-실속종신보험 (무배당)의 보험기간은 어떻게 구분되나요?

답 : 교보K-실속종신보험 (무배당)의 보험기간은 “제1보험기간”과 “제2보험기간”으로 구분하
     며, “제1보험기간” 및 “제2보험기간”은 아래에서 정한 기간으로 합니다.
-    제1보험기간 : 계약일부터 5년경과 계약해당일 전일까지
-    제2보험기간 : 5년경과 계약해당일부터 종신까지

문 : 교보K-실속종신보험 (무배당)의 보험기간별 보험금은 어떻게 되나요?

답 : 피보험자가 보험기간 중 사망하였을 경우 지급되는 보험금은 아래와 같습니다.
1. 제1보험기간 중 재해로 사망한 경우 : 재해사망보험금
2. 제1보험기간 중 재해이외의 원인으로 사망한 경우 : 질병사망보험금
3. 제2보험기간 중 사망한 경우 : 사망보험금
```

분류: 지급사유가 '보험기간 구간 × 원인(재해/재해 이외)'로 분기. 구간 경계 = '5년경과 계약해당일'.

## 보험금 지급내용 표(제1보험기간 질병사망 = 50% + 매년 10% 체증)

             사망하였을 경우                   + 추가계약자적립액

             피보험자가 제1보험기간 중 재해 이 일부터 매년 보험가입금액의 10% 씩 정
 질병사망보험금
             외의 원인으로 사망하였을 경우               액 체증

                                             (기준 : 보험가입금액 )
   급부명                지급사유                  지급내용

  사망보험금

금액 식: 재해사망 = 기본보험금액 + 추가계약자적립액, 질병사망 = 기본보험금액 50% + 1년경과 계약해당일부터 매년 보험가입금액의 10%씩 정액 체증 + 추가계약자적립액. '기본보험금액'은 각주 2에서 저해지기간 전후로 정의가 바뀐다(가입금액 vs max(기본사망보험금, 기본계약자적립액 101%, 이미 납입한 기본보험료)). 상한(100%)이 표에 명시되지 않음 — 약관 별표1 (주) 확인 필요.

## 재해사망특약 지급표

```text
[PDF p.19]
6. 재해사망특약

    급부명칭                 지급사유                    지급액

               피보험자가 이 특약의 보험기간 중 발생한        특약보험가입금액의
  재해사망보험금
               재해로 사망하였을 경우                      100%
1. 이 특약의 보험료 납입기간 중 이 특약의 피보험자가 약관 장해분류표 중 동일한 재해 또는 재해 이외
  의 동일한 원인으로 여러 신체부위의 장해지급률을 더하여 50% 이상인 장해상태가 되었을 경우에는
  이 특약의 차회 이후의 보험료 납입을 면제합니다. 또한, 이 특약의 피보험자와 주계약의 피보험자가 동
  일한 경우 이 특약의 보험료 납입기간 중 주계약에서 정한 보험료 납입면제 사유에 따라 주계약의 보험
  료 납입이 면제된 경우에는 이 특약의 차회 이후의 보험료 납입을 면제합니다.
2. 이 특약의 보험기간 중 피보험자가 재해 이외의 원인으로 사망한 경우에는 회사는 사망 당시의 계약자
  적립액을 계약자에게 지급하고 이 특약은 더 이상 효력을 가지지 않습니다.
```

특약 종속/연동: 특약 피보험자 = 주계약 피보험자일 때 주계약 납입면제에 연동. 재해 이외 사망 시 특약 소멸 + 계약자적립액 지급.

## 일반적인 보험금 지급 제한 사유(요약서 — 자살 2년 예외 누락)

```text
[PDF p.32]
 ① 보험 당사자간의 보험사고가 발생한 경우 지급 제한
   가. 피보험자가 고의로 자신을 해친 경우
   나. 보험수익자가 고의로 피보험자를 해친 경우
    그러나, 그 보험수익자가 보험금의 일부 보험수익자인 경우에 다른 보험수익자에 대한
    보험금은 지급합니다.
   다. 계약자가 고의로 피보험자를 해친 경우
```

요약서는 고의 자해 면책만 쓰고 약관 제8조의 예외(심신상실, 보장개시일부터 2년 경과 후 자살 → 질병사망보험금)를 생략했다(kyobo_wholelife_terms 참조). 요약서 문장만으로 규칙을 만들면 예외가 빠진다 → 설명 문장은 요약서, 실행 규칙은 약관을 근거로 해야 하는 사례.
