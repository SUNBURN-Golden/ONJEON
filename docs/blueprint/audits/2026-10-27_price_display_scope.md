# Audit 2 — 공개 가격 표시: 범위와 활성화 관문 정리

대상: `audit2-price-display-scope`. 결정 메모: [audit2-price-display-scope](../../decisions/audit2-price-display-scope.md).
연결: Blueprint §7.1·§12, 결정 원장 D08·O04·O10·§3.1, README, 09 제품 목적 대응표 P02·P09, [ADR-0010](../../decisions/ADR-0010-선택화면과-공개가격-비교.md), [DEC-D-18](../../decisions/DEC-D-18.md), [DEC-O04](../../decisions/DEC-O04.md).

## 발견

Blueprint §7.1 "첫 출시 데이터" 행, 결정 원장 D08, README는 공개 가격의 수집·표시·비교를 첫 출시 범위로 적는다. 09 P02·P09는 가격 표시를 "D-18·O04 뒤"로 미룬다. D-18은 결정 원장에서 찾을 수 없었다. 감리는 어느 쪽이 정본인지, D-18을 등록해야 하는지 물었다.

## 답

두 문서는 서로 다른 것을 말한다.

- **범위의 정본**은 ADR-0010 → Blueprint §7.1·결정 원장 D08·README다. 공개 가격 수집·표시·비교는 첫 출시 범위이며 이번 정리로 빠지지 않는다.
- **활성화 시점의 정본**은 결정 원장 §3의 관문 행(O04, O10)이다. 09 P02·P09는 이 관문을 완료 증거 조건으로 옮겨 적은 것이고, P09는 이미 "축소 아님"이라고 적고 있었다.

D-18은 이미 [DEC-D-18](../../decisions/DEC-D-18.md)(2026-10-15 위임 결정)로 기록돼 Blueprint §11 결정 색인에 있다. O04도 [DEC-O04](../../decisions/DEC-O04.md)(2026-10-15, 자동 개발 루프의 가역 결정)로 기록돼 있다. 그래서 새 D-18 결정을 만들지 않았다. 실제 결함은 원장 §3.1·O04·O10 행과 Blueprint §12가 두 기록을 참조하지 않은 것, 그리고 "D-18"(O10 결정 항목)과 원장 §1의 "D18"(R2 초기 운영)이 이름이 겹친 것이었다.

## 수정

| 위치 | 변경 |
|---|---|
| 결정 원장 §3 O04 행 | DEC-O04로 해결 표시. 동일 조건·묶음·합계 규칙 요약, 사용자 확정 아님·가역 표시. T-KN-09 `compare_price`는 I7·I8·K13·묶음 시험 통과 뒤 활성, 가격 열 대외 공개 표시는 D-18 뒤. "근거 없는 합계·절감액 금지"는 유지 |
| 결정 원장 §3 O10 행 | DEC-D-18 기록 연결. 외부 검토 담당은 아직 지정되지 않았다는 남은 조건과 "법적 판단이 아니다"를 명시. 허용 범위(설계·내부 개발, 가격 저장·비교 자격 판정·내부 개발 화면)와 차단 범위(대외 공개 표시·대외 출시 판정)를 분리 |
| 결정 원장 §3.1 | DEC-D-18·DEC-O04 행 추가. DEC-D-18 행에 "§1 D18(R2 초기 운영)과 다른 항목"을 적어 이름 충돌을 해소 |
| Blueprint §7.1 "첫 출시 데이터" 행 | 공개 가격 뒤에 범위 안임과 표시 관문(DEC-D-18), 규칙 기록(DEC-O04)을 덧붙임 |
| Blueprint §12 | "외부 검토 담당 지정(D-18·O10)" 행 추가(막는 마일스톤: 대외 출시) |
| README 가격 문단 | 같은 관문 문구와 DEC-D-18·DEC-O04 링크, "범위 축소 아님" |
| 09 P02·P09 비고 | "O04는 DEC-O04로 해결", D-18은 "외부 검토 담당 미지정"으로 남김. 범위 축소 아님 유지 |

일곱 곳 모두 같은 관문 문구 "가격 열 대외 공개 표시는 D-18(O10) 외부 검토 담당 지정 뒤"를 쓴다. DEC 기록 파일·ADR은 바꾸지 않았다.

결정 메모 (6)은 "모든 DEC-D-*/DEC-O* 파일이 §3.1 행을 가진다"는 시험을 제안했다. 그러나 §3.1은 일부 기록만 색인하는 표로 정의돼 있고 기존 [결정 기록 시험](../../../tools/tests/test_decision_records.py)이 이를 고정한다. 그래서 시험은 규칙을 좁혔다: §3의 O 행이나 Blueprint §12 행이 인용하는 DEC 기록은 모두 §3.1에 행이 있어야 한다. 이 규칙은 이번에 추가한 두 기록과 기존 DEC-D-02·D-04·D-12에 모두 적용된다.

## 정정·회귀 증거

- [정정 전후 대조](../../../tools/evidence/audit2-price-display-scope/price-display-scope.diff): 네 문서에서 행 7곳을 바꾸거나 추가했다.
- [수정 전 시험](../../../tools/evidence/audit2-price-display-scope/before.log): 문서를 고치기 전에 새 시험을 실행했고 실패했다(§3.1 행 없음, O04·O10 행이 DEC 미참조, 09 구 문구, §12 행·보고서 없음).
- [가격 표시 범위 시험](../../../tools/tests/test_price_display_scope.py): 범위 정본(D08·§7.1·README)이 첫 출시 범위를 유지하는지, 일곱 곳이 같은 관문 문구와 DEC-D-18을 쓰는지, O04·O10·§3.1·§12 행의 내용, 관문 행이 인용한 DEC의 §3.1 색인 여부(행을 지운 변이 포함), D18/D-18 혼동 금지, 이 보고서의 링크를 검사한다.

## 남은 공백

- 외부 검토 담당은 아직 지정되지 않았다. 지정되기 전까지 가격 열은 대외 공개할 수 없다. 담당 지정은 이 노드의 범위 밖이며 DEC-D-18의 재검토 조건을 따른다.
- DEC-O04와 DEC-D-18은 사용자가 직접 확정한 결정이 아니다. 사용자가 확정·변경하면 원장 행을 다시 맞춘다.

이 보고서는 문서 사이의 참조와 관문 문구를 맞춘 기록이다. 추천·가격 비교·상담의 적용 요건에 대한 법적 판단이 아니다. `compare_price` 활성화나 가격 수집·표시 구현을 증명하지 않으며 P02·P09의 완료를 대신하지 않는다.
