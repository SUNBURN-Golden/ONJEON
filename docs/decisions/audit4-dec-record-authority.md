# Decision: authority of delegated DEC records and direct owner rulings

Node `audit4-dec-record-authority`

Decided by Claude Sonnet 5.5 xhigh (ONJEON autoloop, 2026-11-04 14:50 KST); reversible.

**Decision:** DEC는 기존 설계·위임 범위 안의 조건부 개발 기준과 결정 증거로 유효하다. 전부 ADR로 전환하거나 소유자 재승인을 받을 필요는 없다. 다만 상위 결정·게이트 정의·완료 기준을 변경하려면 ADR → BLUEPRINT §7 갱신과 관련 계약 동기화가 필요하다. 소유자 승인이 요구되는 사항은 별도 승인을 충족해야 하며, ADR 작성만으로 승인되지 않는다. 기존 게이트의 조건 충족과 등록은 게이트 정의 변경과 구분한다. DEC 존재·색인·자동 루프 완료만으로 게이트를 해제하지 않는다.

**Authority classification (2026-11-04):** 기록 시각과 근거에 따라 나눈다. 기록된 위임(2026-10-15 14:44 KST)은 그 이전 기록을 소급 승인하지 않는다.

**O04:** [DEC-O04](DEC-O04.md)는 게이트 정의 변경이 아니라 기존 O04 관문의 조건 충족 기록이다. O04 관문과 T-KN-09 `compare_price`의 release 조건은 이미 tasks.json·ADR-0010·PREMIUM_DATA_CONTRACT에 있었고, DEC-O04는 같은 조건을 시험 가능한 정확 일치·묶음·합계·차액 규칙으로 좁혔다. 그러므로 ADR이나 소유자 재승인으로 게이트를 새로 만들 필요는 없지만, 기록 자체가 관문을 해제하지도 않는다. DEC-O04의 "recording this lifts the O04 release gate" 문장은 같은 문장의 괄호 조건(I7·I8·K13·묶음 시험 통과)과 기존 등록 절차를 전제로 읽는다. `compare_price`는 그 시험이 통과하고 기존 등록 절차가 끝난 뒤에만 활성화된다. DEC-O04는 위임 전 기록이므로 소유자 확정으로 승격하지 않으며, O04의 재검토 조건이나 게이트 정의·완료 증거 기준을 바꾸려면 ADR → §7과 필요한 소유자 승인을 따른다.

**Delegation basis:** [DEC-O17](DEC-O17.md)은 2026-10-15 14:44 KST 소유자 위임 원문과 제외 범위를 직접 기록한다. 비용·하드웨어·메인넷·비밀 키·운영 배포·결제는 위임에서 제외된다. 이 근거는 2026-10-15 14:44 KST 이후 기록에만 적용되며 이전 기록을 소급 승인하지 않는다. 또한 각 DEC에 적힌 범위·조건을 확대하거나 실제 작업을 승인하지 않는다.

**Why:** [BLUEPRINT §0.1](../BLUEPRINT.md#01-문서-위계)은 DEC가 ADR을 대신하지 않는다고 명시하고, §10 규칙 3은 결정 변경에 ADR → §7을 요구한다. [ADR-0019](ADR-0019-제품-완료와-작업-계약-한정-채택.md)도 같은 경계를 유지한다. D-04·D-12의 직접 결정은 명시된 범위에서 존중하되 다른 관문까지 면제하지 않는다. 직접 결정이 이 두 기록뿐이라는 뜻은 아니다. [DEC-BUNDLE-STATUS](DEC-BUNDLE-STATUS.md)의 (1) 실행 기준 채택도 2026-10-13 사용자 결정을 어시스턴트가 기록한 것이며, (2) 정본 지위 구분은 위임 결정이다. D-02·O12는 사용자 확정이 아닌 잠정 개발 기준이다. O04·D-07·D-16도 위임 전 autoloop 기록이므로 위임 결정으로 소급하지 않고, D-08은 2026-10-12 소유자 결정을 확인한 부분만 그 결정에 기댄다. 이 기록들은 기존 계약을 시험 가능하게 만드는 설계 범위에서만 조건부 개발 기준이 된다.

**Evidence:** 최초 결정 시 test_decision_records·test_decisions_ledger_sync·test_purpose_table_decision_sync 39개와 StartGateEnforcement·PrereqAndMergeGateCond 19개가 통과했고, blueprint_status.py는 ADR/DEC 37개 색인을 확인했다. 수정 1~4차의 재현 명령·실행 로그와 PR 본문은 [검증 증거](../../tools/evidence/audit4-dec-record-authority/README.md)에 보관한다. 수정 4차는 위 표의 위임 전 기록 분류와 O04의 조건 충족 해석을 회귀 시험으로 고정한다. 이 증거는 권위 구분과 기존 게이트 동작을 확인하며, 소유자 승인이나 09 제품 완료 증거를 대신하지 않는다. 이 결정은 기존 변경 절차의 해석이며 게이트 정의·등록·승인 상태를 변경하지 않는다.
