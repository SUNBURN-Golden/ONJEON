# Audit 5 — BLUEPRINT §12 결정 기록 동기화

기록일: 2026-11-10. 노드: `audit5-blueprint-s12-sync-decisions`.
연결: BLUEPRINT §12, [결정 원장 §3.1](../DECISIONS.md#31-결정-게이트-기록-dec-),
[DEC 기록 디렉터리](../../decisions/README.md).

## 감리 지적과 조치

감리 지적: §12가 DEC 기록이 이미 해결한 결정 질문을 열린 결정처럼 계속
나열한다. 지목된 항목은 D-02(AI 제공자 구성·정책 소유자), D-03(서비스
실행 클라우드), D-08("필요한 돈" 기본값), D-12(원문 발췌 표시, O16 중 앱
표시 범위), O12(DSL 의미론·범위 비교), O14·O17(보수적 기본값)이다.

§12를 두 부분으로 나눴다. §12.1은 DEC·ADR 기록이 결정 질문을 해결한
사항이고, §12.2는 아직 결정 기록이 없는 항목이다. 지목된 결정 질문은
모두 §12.1로 옮기고 기록 링크와 남은 실행·확인 조건을 같은 행에 적었다.
§12.2에는 O19, O15, 색 토큰·시안 추가 요소, 공개 웹 도메인·명칭만 남겼다.
기존 §12 행의 링크·수치·관문 정보는 유지했고, 결정 내용·승인 상태를
바꾸지 않았다. 위임 결정은 여전히 사용자 확정과 구분하며, DEC 기록의
존재만으로 접근·가동 관문이 열리지 않는다.

| 지목 항목 | §12.1 결정 기록 | 남은 조건(요약) |
|---|---|---|
| AI 제공자 구성 | [DEC-D-02](../../decisions/DEC-D-02.md) | 비-claude 접근 확인·월 한도 확인, 게이트 등록, 임계값 수치(O06·D-19) |
| 정책 소유자 지정 | [DEC-D-02](../../decisions/DEC-D-02.md) | 임계값 수치 확정, 사용자 확정 대기 |
| 서비스 실행 클라우드 | [DEC-D-03](../../decisions/DEC-D-03.md) | 운영 공급자·지역·DB·비용은 S2 실측 뒤 별도 결정. 그 전 스테이징·리허설 차단 |
| "필요한 돈" 기본값 | [DEC-D-08](../../decisions/DEC-D-08.md) | 첫 출시 defaults_enabled=false·user_assumption만. 기본값 도입은 O05 별도 소유자 결정 |
| 원문 발췌 표시(O16) | [DEC-D-12](../../decisions/DEC-D-12.md) | 앱 표시 허용은 해결. 공개 저장소의 새 발췌 추가·표시 플래그 적용·게이트 등록은 별도 |
| DSL 의미론(O12) | [DEC-O12](../../decisions/DEC-O12.md) | release 게이트 등록·연산별 S6 검증, 미충족 연산 capability-blocked |
| R2 버킷 잠금(O14) | [DEC-O14](../../decisions/DEC-O14.md) | 기간·잘못 잠긴 객체 처리·ledger/ 보호·파생 버킷 선택, 적용 승인 |
| 대량 자동 수집(O17) | [DEC-O17](../../decisions/DEC-O17.md) | 원장 체크포인트·O14·토큰 재발급·청구 대조·실제 R2 검증, 그 전 차단 유지 |

이 변경은 결정을 새로 내리거나 승인 상태를 승격하지 않는다. 문서 정합성
수정이며 실제 데이터 접근·수집·배포·출시 완료 증거가 아니다.

## 회귀 시험

[tools/tests/test_blueprint_s12_sync_decisions.py](../../../tools/tests/test_blueprint_s12_sync_decisions.py)는
감리 지적을 구조로 고정한다. §12.1에 지목된 결정 질문이 각각 정확히 한
행 있고 DEC 링크와 남은 조건을 포함하는지, §12.2에는 같은 질문이 다시
열린 항목으로 남지 않는지, §12.2가 결정 기록 없는 항목만 담는지, §12가
참조하는 DEC 파일이 실제로 있는지 검사한다. 수정 전 §12에서 실행하면
§12.1이 없어 실패하고, 수정 후 7건이 통과한다. 로그는
[evidence README](../../../tools/evidence/audit5-blueprint-s12-sync-decisions/README.md)에
명령·종료 코드와 함께 기록한다.
