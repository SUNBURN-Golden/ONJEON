# 결정 기록 탐색

구현의 단일 기준은 [BLUEPRINT](../BLUEPRINT.md)다. ADR은 설계도 변경 경로이고 DEC는 결정 게이트의 범위·상태·조건을 남긴다. 아래는 전체 DEC 원문 색인이다. 현행 요약은 [결정 원장 §3.1](../blueprint/DECISIONS.md), 잔여 조건은 [BLUEPRINT §12](../BLUEPRINT.md#12-열린-결정), 작업 적용은 [그록봇 인계 §10.2](../blueprint/proposals/설계검토_결과/그록봇_인계/README.md)를 따른다.

O01은 ADR-0018로 해결했고 O04·O12의 규칙·의미론 질문도 각 DEC로 해결됐다. D-02 구성·소유자 결정과 실제 접근 확인은 별개다. 위임 결정은 사용자 확정으로 승격하지 않는다. 문서 색인은 `decisions_recorded` 등록이나 접근·실행·병합·출시 승인이 아니다.
