# 09. 제품 목적 대응표: 제품 목적 → 소비자 기능 → 데이터·레이블 → 트윈 → 화면 → 작업 → 완료 증거

작성 2026-10-13 | 지위: [ADR-0019](../../../decisions/ADR-0019-제품-완료와-작업-계약-한정-채택.md)로 BLUEPRINT 하위 계약에 한정 채택한 제품 완료 증거 기준. 상위 계약을 우선한다. **그록봇 인계 계획의 최상위 완료 기준**(사용자 진행 지시 2026-10-13)이며 묶음 전체·참조된 온톨로지 제안의 정본 채택은 아니다. 08_요구추적표(R01~R26, Q1~Q7)와 서로 참조한다(이 표의 P 번호 ↔ 08의 R·Q 번호).

## 0. 최상위 기준(사용자 원문 요지)

- 만드는 것은 **세 부분이 끝까지 연결된 완성품**이다: 철저한 데이터 수집·관리·레이블링 → 그것을 기반으로 한 수준 높은 디지털 트윈 → 소비자가 쉽게 이해하는 직관적 UX/UI.
- 목적은 보험 소비자와 공급자 사이의 **정보비대칭을 줄이는 것**이다. 소비자가 설계사의 설명을 검증하고, 불필요하거나 불리한 선택을 스스로 구별할 수 있어야 한다.
- 이 목적은 소개 문장이 아니라 **실제 작업과 완료 기준**에 연결된다(아래 표의 "구현 작업"·"완료 증거" 칸, tasks.json의 done_criteria·required_test_ids).
- **일부 상품 시연이나 자동 개발 데몬 완성을 첫 출시 완성품으로 바꾸지 않는다.** 데몬 과제(T-OP-00·T-OP-09)는 개발 도구이며 출시 완성품의 일부가 아니다. 최종 관문(T-OP-08)은 이 표의 모든 행(축소·후속 표시 제외)이 등록부 증거로 닫혀야 통과한다.
- 칸의 뜻: 완료 증거 = 실제 데이터·실제 화면 시험·출시 증거(`docs/release-readiness/evidence/`). 합성 픽스처 통과는 증거가 아니다. "축소·후속" 칸은 근거(사용자 결정 ID·정본)가 있을 때만 채운다. 근거 없는 축소는 없다.
