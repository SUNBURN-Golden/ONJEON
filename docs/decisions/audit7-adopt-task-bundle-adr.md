# Audit 7: 작업 계약 채택·단계·관문 정합화

날짜: 2026-11-18 | 상태: 문서 정합성 finding 해결(제품 관문 통과 아님)

**Decision:** [ADR-0020](ADR-0020-작업-단계와-V1-관문-정합화.md)으로 기존 ADR-0019의 한정 채택을 유지하고 S0~S5와 M0~M6의 대응, T-OP-02의 V1 비대체, 조기 rule-0.2의 로컬 엔진·픽스처 한정 예외를 정식 기록했다.

**Why:** ADR-0019와 BLUEPRINT §0.1에는 이미 두 계약이 채택되어 있었다. 남은 순서 충돌을 해소하도록 새 ADR, BLUEPRINT §7·§9·§11·§13, ADR-0014 후속 주석, 원장, tasks.json과 09를 함께 갱신했다. 이전 기록의 읽기 전용·미저장·미해결 설명은 실제 파일 상태와 맞지 않아 삭제했다. 변경 후 실행한 [회귀·프로젝트 시험 증거](../../tools/evidence/audit7-adopt-task-bundle-adr/README.md)를 따른다. 부모 커밋 시험을 새 결정의 검증으로 인용하지 않는다.

**Options:** 대안과 선택 근거는 ADR-0020에 기록한다.

**Revisit if:** 단계 배치·완료 기준 변경, 조기 연산의 서비스 유입, 실제 사례와 연산 의미의 충돌. V1과 첫 출시 관문은 계속 미통과다.
