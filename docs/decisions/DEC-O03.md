P04의 `label-kinds-complete` 의존성을 유지한다. 사전은 보장 대상·지급 사유·제외·면책·감액·한도·갱신·가입 제약·담보 간 관계·특약 종속의 10종을 덮는다. 종류마다 정의·포함/제외 예·근거 연결 규칙이 필요하다. 질병 코드에는 체계·개정차수·시행일·공식 출처와 판 간 매핑이 필요하며 미확정 매핑을 추측하지 않는다. 이 기록은 실제 사전이나 코드 매핑을 만들어 승인한 것이 아니다.

T-KN-05가 `data/label-dictionary/**`에서 M1 완료 전에 작성·검토를 맡는다. 승인할 사전 판과 내용 해시, 코드 개정판 매핑, 검토자·검토 결과·증거 참조를 이 기록에 연결하고 별도 등록해야 승격할 수 있다. T-KN-08(S2)은 이를 소비하며 사전 확정을 S2까지 미루지 않는다.

미등록 O03·미승인 사전·불명확 매핑은 정규 라벨 승격을 거부해야 한다. 후보 추출·형식 정의·로컬 시험·병합은 허용한다. D-02 검수와 accepted 전환 조건은 별개다. 등록 후에도 실제 표본에서 각 종류의 accepted 주장과 basis 근거를 요구하며 종류 누락은 KnowledgeGap으로 기록하고 P04 실패로 남긴다. 합성 사례나 승인 기록만으로 P04가 완료되지 않는다.

`daemon_rules.json`의 release 관문은 데몬 밖 서비스 검사다. 현행 저장소에는 knowledge 서비스 승격 경로가 없으므로 이 변경은 과제 계약·검증 의무를 연결하며 실제 승격 검사를 구현 완료했다고 주장하지 않는다. T-KN-05의 거부 시험·감리 증거 없이는 M1 완료를 주장할 수 없다. 사전 판·분류 의미·매핑·담당 범위가 바뀌면 재검토한다.
