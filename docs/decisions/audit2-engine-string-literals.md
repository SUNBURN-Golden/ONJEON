Decided by Claude Sonnet 5.5 xhigh (ONJEON autoloop, 2026-10-28 08:18 KST); reversible.

**Decision:** M2 실제 라벨 컴파일 전에 명시적 문자열 리터럴 {"str":"..."}을 추가한다. rule-0.1·rule-0.2에서 Expr::Lit(Value::Str)로 처리하고, 기존 일반 문자열의 입력 참조·요율 해석은 유지한다. 새 컴파일 출력은 {"eq":[{"input":"event"},{"str":"surgery"}]}처럼 명시한다.

**Why:** rule.rs:673의 입력명 우선 조회·요율 파싱과 문자열 생성자 부재를 읽기 전용 정적 검사로 확인했다. eval.rs:196에는 문자열 비교가 이미 있어 변경 범위가 작다. BLUEPRINT §9.3의 라벨→규칙 컴파일에 필요한 표현력 보완이며 가역적인 코드 변경이므로 critical=false다. 완료 조건은 두 DSL 버전에서 eq/ne 일치·불일치, 입력명 충돌, 숫자형 문자열, 한글·빈 문자열, 입력 누락/null의 Unknown, 비문자열 인자·추가 키·타입 불일치·순서 비교 거부를 회귀시험으로 검증하는 것이다. rule_operator 정본·어휘 시험·DSL 문서를 함께 갱신하고 기존 골든 결과와 해시 보존 증거를 남겨야 한다. 이번 세션은 읽기 전용이므로 구현 및 런타임 시험은 수행하지 않았으며, finding 해결 완료를 주장하지 않는다. 이 수정만으로 09_제품목적_대응표의 P04·P14 실제 데이터·근거 추적 완료 증거를 대체할 수 없다.
