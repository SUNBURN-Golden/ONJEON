# Audit 7 첫 목록 조회의 수락 범위

2026-11-19(KST) 재검토에서 제시한 수락 범위 조정 경로를 적용한다. 이 노드의 수락 기준은 **현재 실행 환경에서 허용된 첫 출처 목록은 출처가 나타내는 종료 지점까지 읽어 ExpectedDocument 후보로 기록하고, 접근할 수 없는 조회 범위는 최초 제한 응답과 재개 조건을 남기는 것**이다. 대상은 KLIA·KNIA 상품비교공시와 원장의 확인된 회사 진입점 8곳이다. [실측 기록](../blueprint/audits/2026-11-18_enumerate_products_first_source.md).

| 출처 | 접근 증거 | 재개 조건 |
|---|---|---|
| KLIA `pub.insure.or.kr` | robots.txt 200, 일반 크롤러 전체 금지 | 해당 경로를 허용하는 정책 변경 또는 협회가 제공한 재사용 허용 목록 |
| KNIA `kpub.knia.or.kr` | robots.txt HTTP 403. 저장소의 보수적 규칙에 따라 목록 보류 | O19 환경에서 robots 재확인. 차단이 지속되면 협회가 제공한 재사용 허용 목록 |
| DB손해보험 `www.idbins.com` | robots.txt 200, 일반 크롤러의 공시 경로 금지 | 해당 경로를 허용하는 정책 변경 또는 보험사가 제공한 재사용 허용 목록 |
| 처브라이프생명·교보라이프플래닛·미쓰이스미토모 한국지점 | robots.txt 요청이 TLS 연결 단계에서 종료. 원인은 미확정 | O19 환경에서 TLS 및 robots 정책 재확인 |

협회 사이트에서 연결하는 보험다모아는 가입 가능한 상품을 비교하고, 예금보험공사의 공개 API는 예금자보호 대상 상품을 조회한다. 이들 서비스의 설명으로는 요청한 협회 조회 범위와의 일치를 입증할 수 없다. 보험사별 안내 페이지나 단일 상품 파일도 전체 목록의 종료 증거가 될 수 없다. [KNIA 조회 서비스 안내](https://edu.knia.or.kr/edu/knowledge1.do), [예금보험공사 API 설명](https://www.data.go.kr/data/3037352/openapi.do).

10월 KNIA 조사에는 일부 비교공시 조회의 해시와 집계가 있다. 당시 robots.txt도 403이었고 목록 응답 사본은 해당 세션에만 남았다. 이번 원장에는 새 관측에서 확인한 접근 상태와 파싱 가능한 목록으로부터 생성한 행을 기록한다. [10월 KNIA 조사](../research/2026-10-10_source_survey/B_knia.md).

전체 제품·문서 분모는 ADR-0013과 T-DT-04 실데이터 관문 O19를 따른다. 이번 수락 범위는 단일 수동 목록 관측에 적용한다. 접근이 회복되면 같은 계획으로 다시 조회해 열린 범위의 분모 증거를 추가한다. [ADR-0013](ADR-0013-전체-대상-목록-우선과-설계-확정.md), [O17 수집 운영 기준](DEC-O17.md), [결정 원장 O19](../blueprint/DECISIONS.md#3-결정-상태와-남은-차단-조건).
