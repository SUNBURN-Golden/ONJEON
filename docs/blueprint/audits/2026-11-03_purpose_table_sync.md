# Audit 4 — 09 "축소·후속" 셀의 결정·잔여 조건 동기화

대상: `audit4-purpose-table-sync`, 2026-11-03. 단일 기준은 [BLUEPRINT](../../BLUEPRINT.md), 제품 완료 증거 기준은 [09 제품 목적 대응표](../proposals/설계검토_결과/09_제품목적_대응표.md)다. BLUEPRINT A1~A6·Q1~Q7, L1·L4·L8·L9, I6·I14·I18, §12의 결정·관문 추적에 연결한다.

09의 여섯 "축소·후속" 셀에 이미 기록된 결정이 반영되지 않았다. 단순한 결정 대기나 초안 전용으로 읽히던 문구를 원문 결정의 범위·결정 주체·남은 실행 조건으로 교체했다.

P14는 소유자 직접 결정이고 나머지는 위임 결정·사용자 확정 아님을 명시한다. 기존 셀의 결정 대기를 실제 접근·등록·구현·실측 미완료와 구분했으며, 이 잔여 조건은 행 전체를 출시 완료 판정에서 제외하는 근거가 아니다. P01·P02·P09·P18의 기존 범위·가격 공개 관문·후속 표시는 유지한다.

회귀 검사는 수정한 셀 자체의 결정 내용·결정 주체·잔여 조건, DEC 직접 링크와 해당 tasks.json 게이트의 대응을 확인한다. 완료 증거 열에는 실제 관측·검수·화면·참가자 시험 요구가 유지되는지도 검사한다. 기존 CI의 Python 전체 발견 명령이 새 시험을 실행한다. [실행 명령·결과·로그](../../../tools/evidence/audit4-purpose-table-sync/README.md).

이번 변경은 문서 정합성 finding의 완료 증거다. 실제 수집·검수·트윈·소비자 화면·이해도 시험·첫 출시 완료 증거를 대신하지 않는다. 결정 원문·tasks.json·데몬 등록·플래그·완료 증거 열은 변경하지 않았다. 새 지출·법적 판단·비밀값·운영 배포 결정도 하지 않았다.
