# Decision: ADR-0013 #5 says "M1은 V1의 관문을 통과한 뒤 시작한다", but `BLUEPRINT.md:253,322` still says V1 is not passed, a

Decided by Claude Sonnet 5.5 xhigh (ONJEON autoloop, 2026-11-20 20:44 KST); reversible.

**Decision:** V1은 미통과다. ADR-0013 제5항의 착수 순서를 어긴 T-CT-01(PR #102, 57f14e7)을 포함해, 기준 커밋 d32d647에서 이미 병합된 T-CT-01~07의 결과물 보존에만 일회성 사후 예외를 적용한다. BLUEPRINT §10 제6항에 따라 T-CT-08을 포함한 신규 M1 작업은 V1 통과까지 착수 보류다. 읽기 전용 체크아웃이므로 판정은 이 JSON에 기록했으며, 새 ADR과 BLUEPRINT §7·§9.2·§11 반영은 남아 있다.

**Why:** Git 1차 부모 이력과 병합 원장에서 T-CT-01~07을 확인했다. 2026-10-09 R2 보고서에서 원본 해시는 14/14 일치했지만 파생물 완전 재현은 8/14였고 6건은 미검증이다. 실제 이종 모델 계열의 ReviewDecision과 화면 S1·S6 해결 증거도 남아 있다. 이번에 관문 규칙·병합 이력·재현 집계를 검사하는 회귀 시험 11개와 validation_check.py가 통과했다. 이 검사는 저장된 증거의 일관성을 확인했다.

**Options:** ['V1 통과로 기록 — 필수 증거 미충족으로 기각.', '이미 병합된 계약 작업의 보존에만 사후 예외 적용 — 채택.', '병합분 전체 되돌리기 — 기존 계약과 후속 작업에 영향을 주면서 V1의 증거 공백은 해소하지 못해 기각.']

**Revisit if:** 전체 파생물 14/14 재현 보고서(미검증·불일치·오류 0), 대상 해시에 연결된 실제 이종 계열 ReviewDecision, S1 라벨 쏠림과 S6 가격 조건 부족을 해결한 화면 사례·회귀 시험을 validation/README.md와 BLUEPRINT §9.2에 연결하면 V1을 재판정한다. 첫 출시 완료는 09_제품목적_대응표의 P01~P19 완료 증거와 T-OP-08로 판정한다.
