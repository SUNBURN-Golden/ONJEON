# ADR-0005 계약 가져오기: PDF 업로드 단일 경로, 선택 사항

상태: 확정(사용자 결정) | 날짜: 2026-10-08 | 근거: 제3부 §47.2, §46.2

## 맥락

기존 보험을 앱이 알아내는 후보는 증권 촬영, 가입내역 PDF, 통합조회 결과, 마이데이터 연계였다. 사용자는 PDF만 하도록 결정했고, 올리는 일은 사용자 몫이며 올리지 않아도 된다고 했다. 보험이 없는 사람과, 부모·자녀 것을 대신 보며 내용을 모르는 사람이 있다.

## 결정

1. 경로는 보험사 앱·웹에서 받은 가입내역·증권 PDF 업로드 하나다. 촬영·사진·통합조회·마이데이터 연계는 만들지 않는다.
2. 업로드는 선택이다. 프로필마다 가입내역 상태 `uploaded / none / unknown / skipped`를 둔다.
3. `unknown`·`skipped`는 보유 보장 미확인이다. 0원으로 계산하지 않으며 유지·보완 판단을 만들지 않는다. `none`은 사용자 진술로 표시한다.
4. 모든 추출 결과는 사용자 확인 후에만 계산에 쓴다.
5. 대리 프로필에도 PDF를 올릴 수 있으나 해당 프로필 안에만 저장하고 계정 간 공유하지 않는다. 건강·가족력·DNA는 본인 프로필에서만 입력한다.

## 결과

- 사용자 부담이 커서 업로드 전환율이 낮을 수 있다. 그 경우에도 '가입내역 없이 보기'가 동작해야 한다.
- 비밀번호로 잠긴 PDF는 비밀번호를 저장하지 않고 처리 직후 폐기한다.
