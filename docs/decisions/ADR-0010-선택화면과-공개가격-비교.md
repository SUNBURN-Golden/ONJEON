# ADR-0010 선택 화면과 공개 가격 비교

상태: 사용자 방향 확정, 세부 구현 설계 초안 | 2026-10-09

사용자는 6300.png를 다시 지정하고 설계를 요청했으며 “가격데이터도 크롤링해야지”라고 명시했다. 공개 가격을 제외하던 ADR-0008·0009와 제3부의 관련 조항을 대체한다.

1. 첨부 이미지를 내 설계의 주 시각 기준으로 저장한다. 월 예산·현재 유지/보완안·담보 행·비교 CTA를 유지한다.
2. 공개 보험료·가입 조건·가격표·기준일을 수집하고 첫 출시에서 조건별 비교에 사용한다. 개인 실견적 연계와 계약 체결을 구현한다는 뜻은 아니다.
3. 예산 입력은 지출 상한이다. 서로 다른 조건의 가격을 내 보험료나 확정 절감액으로 표시하지 않는다.
4. 가격이 없는 상품도 보장 설명과 원문에서 숨기지 않는다.
5. 두 안의 차이는 새 보장뿐 아니라 제외·감액·면책 재시작·비용 기준 차이를 포함한다. 보완안은 사용자 초안이며 가입 권고로 자동 승격하지 않는다.
6. DNA 설계 동결·본인 전용 경계, 가족력 선택 입력, 수집 정확성 원칙은 유지한다.

구현 기준: `docs/design/CONSUMER_FLOW_SPEC.md`, `docs/data/PREMIUM_DATA_CONTRACT.md`. 이미지의 15만 원과 상태 문구는 실데이터 판정 결과가 아니다.
