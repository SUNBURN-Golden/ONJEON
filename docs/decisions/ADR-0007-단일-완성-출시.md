# ADR-0007 단일 완성 출시, 체험판 웹 없음

상태: 확정. 출시 범위 부분은 ADR-0008이 대체 | 날짜: 2026-10-08 | 근거: 제3부 §42·§43

## 맥락

앞선 제안은 첫 공개 마일스톤(M1)을 두고 상담·광고·건강 기능을 후속 단계로 미루는 구조였다. 사용자는 체험판 웹을 만들지 않고, DNA를 제외한 모든 것을 처음부터 완성본으로 출시하도록 결정했다.

## 결정

1. 출시는 한 번이다. 소비자 앱, 공개 웹, 관제 콘솔, 설계사 포털, 상담 연결, 설계 검증, 콘텐츠·광고·구독, 가족력 입력, 실견적 1·2·3단계를 모두 포함한다.
2. DNA 연계는 설계 동결 상태로 출시하지 않는다.
3. 체험판 웹은 만들지 않는다. 앱 안의 '예시로 둘러보기'는 유지한다(가정).
4. 완성은 기능의 완성이다. 담보별 계산은 불변 원칙 3·5·7에 따라 AI 검수를 통과한 것부터 켜지며, 출시 게이트에 "전 담보 계산 가능"은 넣지 않는다(가정).
5. 출시 전에는 비공개 베타 대신 내부 리허설(합성·AI 사용자 시뮬레이션, 롤백·서킷 브레이커 연습)을 한다.

## 결과와 위험

- 범위가 크므로 출시 지연과 품질 저하가 위험이다(제3부 R15). 기능별 출시 게이트를 정의하고, 미통과 시 출시를 미룰지 그 기능을 끌지는 사용자가 정한다.
- 실견적 3단계는 외부 제휴에 달려 있어 제휴가 성립한 곳에서만 켜진다(R16).
- 실사용자 피드백 없이 출시하므로 사용성 시험(5초·30초 기준)과 출시 후 오류 환류 체계를 게이트로 둔다.
